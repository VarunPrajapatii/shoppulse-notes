## Upgrade Scenarios Overview

### Scenario Matrix

| Current Status | Can Upgrade? | Immediate/Scheduled | Special Handling |
|----------------|--------------|---------------------|------------------|
| **ACTIVE** | ✅ Yes | Immediate | Standard flow |
| **CANCELED** | ✅ Yes | Immediate | Also reactivates |
| **COMPLETING** | ✅ Yes | Immediate | Extends beyond period end |
| **PAST_DUE** | ⚠️ Maybe | After payment | Must clear dues first |
| **EXPIRED** | ❌ No | N/A | Must create new subscription |
| **PAUSED** | ⚠️ Maybe | After resume | Resume then upgrade |

---

### Scenario 1: ACTIVE → Higher Tier (Standard Upgrade)

**Example**:
```
User: Monthly plan (₹3,500), Day 10 of 30
Wants: Half-Yearly plan (₹18,000)

Calculation:
- Days remaining: 20
- Unused value: ₹3,500 × (20/30) = ₹2,333.33
- First charge: ₹18,000 - ₹2,333.33 = ₹15,666.67
- New period: Today → Today + 180 days

Steps (SAFE UPGRADE FLOW):
1. Calculate proration credit (₹2,333.33)
2. Create NEW Razorpay subscription with negative addon for credit
   - Plan: Half-Yearly (₹18,000)
   - Addon: -₹2,333.33 (proration credit)
   - First charge shown to user: ₹15,666.67
   - Future charges: ₹18,000 (full price)
3. User sees checkout page (subscription.short_url)
4. User authorizes autopay and pays ₹15,666.67
5. subscription.authenticated webhook fires
6. In webhook: Cancel OLD Monthly subscription
7. In webhook: Update database to new plan
8. User gets immediate access to new limits ✓

CRITICAL: Old subscription canceled AFTER new payment succeeds!
This ensures user never loses access if payment fails.
```

### Scenario 2A: CANCELED → Same Plan (Simple Reactivation)

**Example**:
```
User: Canceled Monthly plan (₹3,500), 15 days remaining
Wants: Same Monthly plan (just changed their mind)

What Happens:
- NO new charge (already paid for 30 days)
- NO new Razorpay subscription needed
- Just remove cancellation flag
- User keeps access until original period end (Nov 30)
- Auto-renewal re-enabled for next cycle

Actions:
1. Check: currentPeriodEnd > today? ✓ (15 days left)
2. Update status: CANCELED → ACTIVE
3. Set canceledAt: null
4. Set cancelAtPeriodEnd: false
5. Set autoRenew: true
6. Keep existing razorpaySubscriptionId (no change needed)
7. Create history: "REACTIVATED - Same plan"

Timeline:
- Today (Nov 18): Reactivation happens, no charge
- Nov 30: Normal renewal charge of ₹3,500
- Next period: Dec 1 → Dec 30
```

**Why Simple**:
- User already paid for full period (Nov 1 → Nov 30)
- Just canceling the cancellation
- No money changes hands
- No Razorpay API calls needed (subscription still exists)
- Simplest flow!

### Scenario 2B: CANCELED → Higher Tier (Upgrade + Reactivation)

**Example**:
```
User: Canceled Monthly plan (₹3,500), 15 days remaining
Wants: Half-Yearly plan (₹18,000) ← DIFFERENT PLAN (upgrade!)

Calculation:
- Days remaining: 15 (even though canceled)
- Unused value from Monthly: ₹3,500 × (15/30) = ₹1,750
- Half-Yearly price: ₹18,000
- Credit applied: -₹1,750
- Charge today: ₹16,250
- New period: Today → Today + 180 days (Nov 18 → May 17)

Actions (Upgrade + Reactivation):
1. Cancel OLD Monthly Razorpay subscription (via API)
2. Create NEW Half-Yearly Razorpay subscription (via API)
3. Update planId: monthly_id → halfyearly_id ← PLAN CHANGE!
4. Update razorpaySubscriptionId: old_sub_id → new_sub_id
5. Update razorpayPlanId: monthly_plan_id → halfyearly_plan_id
6. Update status: CANCELED → ACTIVE
7. Update canceledAt: Set to null
8. Update currentPeriodStart: Nov 18 (today)
9. Update currentPeriodEnd: May 17 (180 days from today)
10. Update limits immediately to Half-Yearly (100 → 500 products, etc.)
11. Create history records: "REACTIVATED" + "UPGRADED"

Database Changes:
┌─────────────────────────────┬────────────────────┬─────────────────────┐
│ Field                       │ Before (CANCELED)  │ After (ACTIVE)      │
├─────────────────────────────┼────────────────────┼─────────────────────┤
│ planId                      │ monthly_plan_id    │ halfyearly_plan_id  │
│ status                      │ CANCELED           │ ACTIVE              │
│ razorpaySubscriptionId      │ sub_old123         │ sub_new456          │
│ razorpayPlanId              │ plan_monthly       │ plan_halfyearly     │
│ currentPeriodStart          │ Nov 1              │ Nov 18 (today)      │
│ currentPeriodEnd            │ Nov 30             │ May 17 (today+180)  │
│ canceledAt                  │ Nov 10             │ null                │
│ cancelAtPeriodEnd           │ true               │ false               │
│ autoRenew                   │ false              │ true                │
└─────────────────────────────┴────────────────────┴─────────────────────┘

Razorpay Actions (SAFE FLOW):
1. Create NEW subscription with proration addon (DON'T cancel old yet!):
   razorpay.subscriptions.create({
     plan_id: "plan_halfyearly",
     customer_id: "cust_123",
     total_count: 6,
     start_at: unix_timestamp_now,
     addons: [{
       item: {
         name: "Upgrade Proration Credit",
         amount: -175000, // -₹1,750 in paise (NEGATIVE!)
         currency: "INR"
       }
     }],
     notes: { 
       oldSubscriptionId: "sub_old123",
       replacingSubscription: "true",
       upgradeType: "reactivation_upgrade"
     }
   })
   Response: { id: "sub_new456", short_url: "https://rzp.io/i/xyz123" }

2. User clicks short_url → Razorpay checkout
   - Shows: ₹18,000 plan
   - First charge: ₹16,250 (after addon credit)
   - User authorizes autopay for ₹18,000

3. User pays → subscription.authenticated webhook fires

4. In webhook handler: Cancel old subscription
   razorpay.subscriptions.cancel(sub_old123)
   Response: {"status": "cancelled"}

5. In webhook: Update database to new plan

WHY THIS ORDER?
- If user abandons payment → old subscription still active (15 days protected!)
- Old subscription canceled ONLY after new payment succeeds ✓
```

**Why Different from 2A**:
- User wants DIFFERENT plan (not same)
- Must create NEW Razorpay subscription (can't modify plan_id)
- Must charge difference (new plan price - credit)
- Gets immediate access to NEW plan limits
- More complex but standard upgrade flow

**Key Insight**:
- Same plan = Simple flag update (no charge, no new subscription)
- Different plan = Full swap (charge, new subscription, cancel old)

### Scenario 4: PAST_DUE → Higher Tier (Pay Dues + Upgrade)

**Example**:
```
User: Monthly plan (₹3,500), PAST_DUE (payment failed 3 days ago)
Wants: Half-Yearly plan (₹18,000)

Approach 1: Clear Dues First
- User must pay ₹3,500 for failed charge
- Then upgrade (standard flow)

Approach 2: Forgive + Upgrade (Generous)
- Skip failed charge
- Charge only upgrade amount
- Create new subscription immediately
- History: Note that dues were forgiven during upgrade

Recommended: Approach 2 (Better UX, user is upgrading = more revenue)

Calculation:
- Forgive failed ₹3,500 charge
- Charge: ₹18,000 (full new plan price, no proration)
- Reason: Current period already expired
- New period: Today → Today + 180 days
```

## Proration Calculator Library

Create comprehensive proration utilities:

```typescript
// src/lib/proration-calculator.ts

import { BillingCycle, SubscriptionStatus } from '@/generated/prisma';
import { 
  differenceInDays, 
  differenceInHours, 
  addDays,
  addMonths,
  addYears 
} from 'date-fns';

/**
 * Get total days in a billing cycle
 */
export function getBillingCycleDays(cycle: BillingCycle): number {
  switch (cycle) {
    case 'MONTHLY':
      return 30;
    case 'HALFYEARLY':
      return 180;
    case 'YEARLY':
      return 365;
    default:
      throw new Error(`Unknown billing cycle: ${cycle}`);
  }
}

/**
 * Get billing cycle count for Razorpay (total_count)
 * 
 * Monthly: infinite (or 12 for 1 year)
 * Half-Yearly: 6 (6 monthly cycles)
 * Yearly: 12 (12 monthly cycles)
 */
export function getBillingCycleCount(cycle: BillingCycle): number {
  switch (cycle) {
    case 'MONTHLY':
      return 12; // 1 year of monthly billing
    case 'HALFYEARLY':
      return 6; // 6 months
    case 'YEARLY':
      return 12; // 12 months (1 year)
    default:
      return 12;
  }
}

/**
 * Calculate new period end date based on billing cycle
 */
export function calculateNewPeriodEnd(
  startDate: Date,
  billingCycle: BillingCycle
): Date {
  switch (billingCycle) {
    case 'MONTHLY':
      return addMonths(startDate, 1);
    case 'HALFYEARLY':
      return addMonths(startDate, 6);
    case 'YEARLY':
      return addYears(startDate, 1);
    default:
      return addMonths(startDate, 1);
  }
}

/**
 * Calculate prorated credit for unused time
 * Uses precise hour-level calculation for fairness
 * 
 * @param planPrice - Original plan price (in rupees)
 * @param billingCycle - MONTHLY, HALFYEARLY, or YEARLY
 * @param currentPeriodEnd - End of current billing period
 * @returns Credit amount in rupees (2 decimal places)
 */
export function calculateProrationCredit(
  planPrice: number,
  billingCycle: BillingCycle,
  currentPeriodEnd: Date
): {
  credit: number;
  daysRemaining: number;
  hoursRemaining: number;
  percentageUnused: number;
} {
  const now = new Date();
  
  // If period already ended, no credit
  if (currentPeriodEnd <= now) {
    return {
      credit: 0,
      daysRemaining: 0,
      hoursRemaining: 0,
      percentageUnused: 0
    };
  }
  
  // Calculate precise time remaining
  const hoursRemaining = differenceInHours(currentPeriodEnd, now);
  const daysRemaining = differenceInDays(currentPeriodEnd, now);
  
  // Convert hours to fractional days for precision
  const fractionalDaysRemaining = hoursRemaining / 24;
  
  // Total days in cycle
  const totalDays = getBillingCycleDays(billingCycle);
  
  // Calculate percentage unused
  const percentageUnused = (fractionalDaysRemaining / totalDays) * 100;
  
  // Calculate credit
  const credit = planPrice * (fractionalDaysRemaining / totalDays);
  
  return {
    credit: Math.round(credit * 100) / 100, // Round to 2 decimals
    daysRemaining,
    hoursRemaining,
    percentageUnused: Math.round(percentageUnused * 10) / 10 // 1 decimal
  };
}

/**
 * Calculate charge amount for plan upgrade
 * 
 * @param oldPlan - Current plan details
 * @param newPlan - New plan details
 * @param currentPeriodEnd - End of current billing period
 * @param currentStatus - Current subscription status
 * @returns Complete calculation breakdown
 */
export function calculateUpgradeCharge(
  oldPlan: {
    price: number;
    billingCycle: BillingCycle;
    displayName: string;
  },
  newPlan: {
    price: number;
    billingCycle: BillingCycle;
    displayName: string;
  },
  currentPeriodEnd: Date,
  currentStatus: SubscriptionStatus = 'ACTIVE'
): {
  // Proration details
  prorationCredit: number;
  daysRemaining: number;
  percentageUnused: number;
  
  // Charges
  newPlanPrice: number;
  chargeAmount: number;
  
  // Classification
  isUpgrade: boolean;
  isSameTier: boolean;
  
  // Special cases
  isReactivation: boolean; // If status was CANCELED
  isExtension: boolean; // If status was COMPLETING
  shouldForgive: boolean; // If status was PAST_DUE
  
  // Explanation
  breakdown: string[];
} {
  // Calculate proration credit
  const proration = calculateProrationCredit(
    oldPlan.price,
    oldPlan.billingCycle,
    currentPeriodEnd
  );
  
  // New plan price
  const newPlanPrice = newPlan.price;
  
  // Special case: PAST_DUE - forgive dues, charge full new plan price
  if (currentStatus === 'PAST_DUE') {
    return {
      prorationCredit: 0, // No credit for expired period
      daysRemaining: 0,
      percentageUnused: 0,
      newPlanPrice,
      chargeAmount: newPlanPrice,
      isUpgrade: newPlanPrice > oldPlan.price,
      isSameTier: newPlanPrice === oldPlan.price,
      isReactivation: false,
      isExtension: false,
      shouldForgive: true,
      breakdown: [
        `Old plan expired (PAST_DUE)`,
        `Forgiving failed charge of ₹${oldPlan.price}`,
        `Charging full price for ${newPlan.displayName}: ₹${newPlanPrice}`,
        `New period starts today`
      ]
    };
  }
  
  // Calculate charge amount
  const chargeAmount = Math.max(0, newPlanPrice - proration.credit);
  
  // Determine classification
  const isUpgrade = newPlanPrice > oldPlan.price;
  const isSameTier = newPlanPrice === oldPlan.price;
  const isReactivation = currentStatus === 'CANCELED';
  const isExtension = currentStatus === 'COMPLETING';
  
  // Build breakdown
  const breakdown: string[] = [];
  
  breakdown.push(`${newPlan.displayName} Plan: ₹${newPlanPrice.toFixed(2)}`);
  
  if (proration.credit > 0) {
    breakdown.push(
      `Credit for ${proration.daysRemaining} days (${proration.percentageUnused.toFixed(1)}%) unused on ${oldPlan.displayName}: -₹${proration.credit.toFixed(2)}`
    );
  }
  
  breakdown.push(`─────────────────────`);
  breakdown.push(`You Pay Today: ₹${chargeAmount.toFixed(2)}`);
  
  if (isReactivation) {
    breakdown.push(``);
    breakdown.push(`✨ Your subscription will be reactivated!`);
  }
  
  if (isExtension) {
    breakdown.push(``);
    breakdown.push(`✨ Extending beyond COMPLETING period!`);
  }
  
  return {
    prorationCredit: proration.credit,
    daysRemaining: proration.daysRemaining,
    percentageUnused: proration.percentageUnused,
    newPlanPrice,
    chargeAmount,
    isUpgrade,
    isSameTier,
    isReactivation,
    isExtension,
    shouldForgive: false,
    breakdown
  };
}

/**
 * Get human-readable upgrade explanation
 */
export function getUpgradeExplanation(
  calc: ReturnType<typeof calculateUpgradeCharge>,
  oldPlanName: string,
  newPlanName: string
): string {
  const lines = [
    `🚀 Upgrade from ${oldPlanName} to ${newPlanName}`,
    ``,
    ...calc.breakdown
  ];
  
  if (calc.isReactivation) {
    lines.push(``);
    lines.push(`Note: Your canceled subscription will be reactivated.`);
    lines.push(`Auto-renewal will be re-enabled.`);
  }
  
  if (calc.isExtension) {
    lines.push(``);
    lines.push(`Note: This extends your subscription beyond the current COMPLETING period.`);
  }
  
  return lines.join('\n');
}

/**
 * Validate upgrade eligibility
 */
export function validateUpgrade(
  oldPlanPrice: number,
  newPlanPrice: number,
  currentStatus: SubscriptionStatus
): {
  canUpgrade: boolean;
  reason?: string;
} {
  // Cannot upgrade if subscription expired
  if (currentStatus === 'EXPIRED') {
    return {
      canUpgrade: false,
      reason: 'Subscription has expired. Please create a new subscription.'
    };
  }
  
  // Cannot upgrade to same or lower price (that's a downgrade)
  if (newPlanPrice <= oldPlanPrice) {
    return {
      canUpgrade: false,
      reason: 'New plan price must be higher than current plan for upgrade. Use downgrade flow instead.'
    };
  }
  
  // PAUSED subscriptions need to be resumed first
  if (currentStatus === 'PAUSED') {
    return {
      canUpgrade: false,
      reason: 'Subscription is paused. Please resume before upgrading.'
    };
  }
  
  // All other statuses can upgrade
  return {
    canUpgrade: true
  };
}
```

## Upgrade API Endpoints

### 1. Calculate Upgrade Preview (GET)

```typescript
// src/app/api/subscription/upgrade/preview/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import { 
  calculateUpgradeCharge, 
  validateUpgrade,
  getUpgradeExplanation 
} from '@/lib/proration-calculator';

export async function POST(req: Request) {
  try {
    const { userId: clerkId } = await auth();
    if (!clerkId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const { newPlanId } = await req.json();
    
    // Get user's current subscription
    const user = await prisma.user.findUnique({
      where: { id: clerkId },
      include: {
        subscription: {
          include: { plan: true }
        }
      }
    });
    
    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No active subscription found' },
        { status: 400 }
      );
    }
    
    const currentSub = user.subscription;
    
    // Get new plan details
    const newPlan = await prisma.subscriptionPlan.findUnique({
      where: { id: newPlanId }
    });
    
    if (!newPlan) {
      return NextResponse.json(
        { error: 'Plan not found' },
        { status: 404 }
      );
    }
    
    // Validate upgrade eligibility
    const validation = validateUpgrade(
      Number(currentSub.plan.price),
      Number(newPlan.price),
      currentSub.status
    );
    
    if (!validation.canUpgrade) {
      return NextResponse.json(
        { 
          error: validation.reason,
          canUpgrade: false
        },
        { status: 400 }
      );
    }
    
    // Calculate upgrade charges
    const calc = calculateUpgradeCharge(
      {
        price: Number(currentSub.plan.price),
        billingCycle: currentSub.plan.billingCycle,
        displayName: currentSub.plan.displayName
      },
      {
        price: Number(newPlan.price),
        billingCycle: newPlan.billingCycle,
        displayName: newPlan.displayName
      },
      currentSub.currentPeriodEnd,
      currentSub.status
    );
    
    // Get explanation
    const explanation = getUpgradeExplanation(
      calc,
      currentSub.plan.displayName,
      newPlan.displayName
    );
    
    return NextResponse.json({
      canUpgrade: true,
      calculation: {
        currentPlan: {
          id: currentSub.planId,
          name: currentSub.plan.displayName,
          price: Number(currentSub.plan.price),
          billingCycle: currentSub.plan.billingCycle
        },
        newPlan: {
          id: newPlan.id,
          name: newPlan.displayName,
          price: Number(newPlan.price),
          billingCycle: newPlan.billingCycle
        },
        proration: {
          credit: calc.prorationCredit,
          daysRemaining: calc.daysRemaining,
          percentageUnused: calc.percentageUnused
        },
        charges: {
          newPlanPrice: calc.newPlanPrice,
          creditApplied: calc.prorationCredit,
          totalCharge: calc.chargeAmount
        },
        flags: {
          isUpgrade: calc.isUpgrade,
          isReactivation: calc.isReactivation,
          isExtension: calc.isExtension,
          shouldForgive: calc.shouldForgive
        },
        explanation,
        breakdown: calc.breakdown
      }
    });
    
  } catch (error) {
    console.error('❌ Upgrade preview error:', error);
    return NextResponse.json(
      { error: 'Failed to calculate upgrade preview' },
      { status: 500 }
    );
  }
}
```

### 3. Verify Payment & Complete Upgrade

```typescript
// src/app/api/subscription/upgrade/verify/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import crypto from 'crypto';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';
import { 
  getBillingCycleCount, 
  calculateNewPeriodEnd,
  calculateUpgradeCharge
} from '@/lib/proration-calculator';
import { invalidateStoreCache } from '@/lib/store-subscription-service';

export async function POST(req: Request) {
  try {
    const { userId: clerkId } = await auth();
    if (!clerkId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const {
      razorpayOrderId,
      razorpayPaymentId,
      razorpaySignature,
      newPlanId
    } = await req.json();
    
    // Verify Razorpay signature
    const secret = process.env.RAZORPAY_KEY_SECRET!;
    const body = razorpayOrderId + '|' + razorpayPaymentId;
    const expectedSignature = crypto
      .createHmac('sha256', secret)
      .update(body)
      .digest('hex');
    
    if (expectedSignature !== razorpaySignature) {
      console.error('❌ Invalid Razorpay signature');
      return NextResponse.json(
        { error: 'Payment verification failed' },
        { status: 400 }
      );
    }
    
    console.log('✅ Payment signature verified');
    
    // Get user's current subscription
    const user = await prisma.user.findUnique({
      where: { id: clerkId },
      include: {
        subscription: {
          include: { plan: true }
        }
      }
    });
    
    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No subscription found' },
        { status: 400 }
      );
    }
    
    const currentSub = user.subscription;
    
    // Get new plan
    const newPlan = await prisma.subscriptionPlan.findUnique({
      where: { id: newPlanId }
    });
    
    if (!newPlan) {
      return NextResponse.json({ error: 'Plan not found' }, { status: 404 });
    }
    
    // Fetch payment details from Razorpay
    const payment = await razorpay.payments.fetch(razorpayPaymentId);
    
    if (payment.status !== 'captured') {
      return NextResponse.json(
        { error: 'Payment not captured' },
        { status: 400 }
      );
    }
    
    console.log(`✅ Payment captured: ₹${payment.amount / 100}`);
    
    // Calculate again for history metadata
    const calc = calculateUpgradeCharge(
      {
        price: Number(currentSub.plan.price),
        billingCycle: currentSub.plan.billingCycle,
        displayName: currentSub.plan.displayName
      },
      {
        price: Number(newPlan.price),
        billingCycle: newPlan.billingCycle,
        displayName: newPlan.displayName
      },
      currentSub.currentPeriodEnd,
      currentSub.status
    );
    
    // TRANSACTION: Cancel old subscription, create new one, update DB
    const result = await prisma.$transaction(async (tx) => {
      // 1. Cancel old Razorpay subscription (if exists and active)
      let oldSubCanceled = false;
      if (
        currentSub.razorpaySubscriptionId && 
        !['EXPIRED', 'CANCELED'].includes(currentSub.status)
      ) {
        try {
          await razorpay.subscriptions.cancel(
            currentSub.razorpaySubscriptionId,
            { cancel_at_cycle_end: false } // Immediate
          );
          oldSubCanceled = true;
          console.log(`✅ Canceled old Razorpay subscription: ${currentSub.razorpaySubscriptionId}`);
        } catch (error) {
          console.warn('⚠️ Failed to cancel old subscription (might be already canceled):', error);
          // Continue anyway - might be already canceled
        }
      }
      
      // 2. Create new Razorpay subscription
      const now = new Date();
      const newPeriodEnd = calculateNewPeriodEnd(now, newPlan.billingCycle);
      
      const newRazorpaySub = await razorpay.subscriptions.create({
        plan_id: newPlan.razorpayPlanId!,
        customer_id: currentSub.razorpayCustomerId!,
        total_count: getBillingCycleCount(newPlan.billingCycle),
        start_at: Math.floor(now.getTime() / 1000), // Unix timestamp
        notify: 1, // Send email to customer
        notes: {
          userId: clerkId,
          replacedSubscriptionId: currentSub.razorpaySubscriptionId || 'none',
          upgradeType: calc.isReactivation ? 'reactivation' : calc.isExtension ? 'extension' : 'standard'
        }
      });
      
      console.log(`✅ Created new Razorpay subscription: ${newRazorpaySub.id}`);
      
      // 3. Update subscription in database
      await tx.subscription.update({
        where: { id: currentSub.id },
        data: {
          planId: newPlanId,
          razorpaySubscriptionId: newRazorpaySub.id,
          razorpayPlanId: newPlan.razorpayPlanId,
          billingCycle: newPlan.billingCycle,
          status: 'ACTIVE', // Always ACTIVE after upgrade
          currentPeriodStart: now,
          currentPeriodEnd: newPeriodEnd,
          nextChargeAt: newPeriodEnd,
          paidCount: 0,
          remainingCount: getBillingCycleCount(newPlan.billingCycle),
          totalCount: getBillingCycleCount(newPlan.billingCycle),
          autoRenew: true, // Re-enable if was CANCELED or COMPLETING
          canceledAt: null, // Clear if was CANCELED
          cancelAtPeriodEnd: false, // Clear if was CANCELED
          updatedAt: now
        }
      });
      
      console.log(`✅ Updated subscription in database`);
      
      // 4. Ensure user is active (especially important for CANCELED/PAST_DUE)
      await tx.user.update({
        where: { id: clerkId },
        data: {
          isActive: true,
          gracePeriod: false,
          trialUsed: true // Mark trial as used if upgrading from trial
        }
      });
      
      // 5. Restore store access (if was blocked)
      await tx.store.updateMany({
        where: { userId: clerkId },
        data: { isAccessible: true }
      });
      
      console.log(`✅ Restored user and store access`);
      
      // 6. Create payment record
      await tx.payment.create({
        data: {
          userId: clerkId,
          subscriptionId: currentSub.id,
          razorpayOrderId,
          razorpayPaymentId,
          razorpaySubscriptionId: newRazorpaySub.id,
          razorpaySignature,
          amountPaid: payment.amount / 100,
          subtotal: payment.amount / 100,
          currency: payment.currency.toUpperCase(),
          status: 'SUCCESS',
          paymentMethod: payment.method,
          description: `Upgrade: ${currentSub.plan.displayName} → ${newPlan.displayName}`,
          paidAt: new Date(payment.created_at * 1000)
        }
      });
      
      console.log(`✅ Created payment record`);
      
      // 7. Create subscription history
      await tx.subscriptionHistory.create({
        data: {
          subscriptionId: currentSub.id,
          action: 'UPGRADED',
          fromPlanId: currentSub.planId,
          toPlanId: newPlanId,
          fromStatus: currentSub.status,
          toStatus: 'ACTIVE',
          prorationCredit: calc.prorationCredit,
          chargeAmount: calc.chargeAmount,
          reason: calc.isReactivation
            ? `Reactivated & Upgraded: ${currentSub.plan.displayName} → ${newPlan.displayName}`
            : calc.isExtension
            ? `Extended & Upgraded: ${currentSub.plan.displayName} → ${newPlan.displayName}`
            : `Upgraded: ${currentSub.plan.displayName} → ${newPlan.displayName}`,
          metadata: {
            oldRazorpaySubId: currentSub.razorpaySubscriptionId,
            newRazorpaySubId: newRazorpaySub.id,
            oldSubCanceled,
            paymentId: razorpayPaymentId,
            prorationCredit: calc.prorationCredit,
            chargeAmount: calc.chargeAmount,
            daysRemaining: calc.daysRemaining,
            percentageUnused: calc.percentageUnused,
            isReactivation: calc.isReactivation,
            isExtension: calc.isExtension,
            shouldForgive: calc.shouldForgive,
            oldStatus: currentSub.status,
            newPeriodStart: now,
            newPeriodEnd: newPeriodEnd
          }
        }
      });
      
      console.log(`✅ Created subscription history record`);
      
      // 8. If reactivation, add extra history entry
      if (calc.isReactivation) {
        await tx.subscriptionHistory.create({
          data: {
            subscriptionId: currentSub.id,
            action: 'REACTIVATED',
            fromStatus: 'CANCELED',
            toStatus: 'ACTIVE',
            reason: 'Subscription reactivated through upgrade',
            metadata: {
              reactivatedVia: 'upgrade',
              newPlanId,
              newPlanName: newPlan.displayName
            }
          }
        });
      }
      
      return {
        newRazorpaySubId: newRazorpaySub.id,
        newPeriodEnd
      };
    });
    
    // Invalidate store cache
    const userStore = await prisma.store.findFirst({
      where: { userId: clerkId },
      select: { id: true }
    });
    
    if (userStore) {
      invalidateStoreCache(userStore.id);
      console.log(`✅ Invalidated store cache: ${userStore.id}`);
    }
    
    console.log(`🎉 Upgrade completed successfully!`);
    console.log(`   New Razorpay Sub ID: ${result.newRazorpaySubId}`);
    console.log(`   New Period End: ${result.newPeriodEnd}`);
    
    return NextResponse.json({
      success: true,
      message: 'Upgrade successful!',
      subscription: {
        planName: newPlan.displayName,
        billingCycle: newPlan.billingCycle,
        periodEnd: result.newPeriodEnd,
        razorpaySubscriptionId: result.newRazorpaySubId
      },
      flags: {
        wasReactivated: calc.isReactivation,
        wasExtended: calc.isExtension
      }
    });
    
  } catch (error) {
    console.error('❌ Upgrade verification error:', error);
    return NextResponse.json(
      { error: 'Failed to complete upgrade' },
      { status: 500 }
    );
  }
}
```

```typescript
'use client';

import { useState } from 'react';
import { useRouter } from 'next/navigation';
import { toast } from 'sonner';
import { Button } from '@/components/ui/button';
import { Loader2, ArrowUp } from 'lucide-react';
import { UpgradePreviewModal } from './upgrade-preview-modal';
import { useRazorpay } from '@/hooks/use-razorpay';

interface UpgradeButtonProps {
  newPlanId: string;
  newPlanName: string;
  currentPlanName: string;
  variant?: 'default' | 'outline' | 'secondary';
  size?: 'default' | 'sm' | 'lg';
  className?: string;
}

export function UpgradeButton({
  newPlanId,
  newPlanName,
  currentPlanName,
  variant = 'default',
  size = 'default',
  className
}: UpgradeButtonProps) {
  const router = useRouter();
  const { initiatePayment } = useRazorpay();
  
  const [isLoading, setIsLoading] = useState(false);
  const [showPreview, setShowPreview] = useState(false);
  const [calculation, setCalculation] = useState<any>(null);
  
  // Step 1: Fetch upgrade preview
  const handleUpgradeClick = async () => {
    setIsLoading(true);
    
    try {
      const response = await fetch('/api/subscription/upgrade/preview', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ newPlanId })
      });
      
      if (!response.ok) {
        const error = await response.json();
        throw new Error(error.error || 'Failed to load upgrade preview');
      }
      
      const data = await response.json();
      
      if (!data.canUpgrade) {
        toast.error(data.error || 'Cannot upgrade at this time');
        return;
      }
      
      setCalculation(data.calculation);
      setShowPreview(true);
      
    } catch (error) {
      console.error('Preview error:', error);
      toast.error(error instanceof Error ? error.message : 'Failed to load preview');
    } finally {
      setIsLoading(false);
    }
  };
  
  // Step 2: Initiate Razorpay payment
  const handleConfirmUpgrade = async () => {
    try {
      // Create Razorpay order
      const response = await fetch('/api/subscription/upgrade/initiate', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ newPlanId })
      });
      
      if (!response.ok) {
        const error = await response.json();
        throw new Error(error.error || 'Failed to initiate upgrade');
      }
      
      const data = await response.json();
      
      // Launch Razorpay payment
      const paymentResult = await initiatePayment({
        orderId: data.orderId,
        amount: data.amount,
        currency: data.currency,
        description: `Upgrade to ${newPlanName}`,
        onSuccess: async (paymentData) => {
          // Verify payment and complete upgrade
          await verifyAndCompleteUpgrade(paymentData);
        },
        onFailure: (error) => {
          console.error('Payment failed:', error);
          toast.error('Payment failed. Please try again.');
        }
      });
      
    } catch (error) {
      console.error('Upgrade error:', error);
      toast.error(error instanceof Error ? error.message : 'Upgrade failed');
    }
  };
  
  // Step 3: Verify payment and complete upgrade
  const verifyAndCompleteUpgrade = async (paymentData: any) => {
    try {
      const response = await fetch('/api/subscription/upgrade/verify', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          razorpayOrderId: paymentData.razorpay_order_id,
          razorpayPaymentId: paymentData.razorpay_payment_id,
          razorpaySignature: paymentData.razorpay_signature,
          newPlanId
        })
      });
      
      if (!response.ok) {
        const error = await response.json();
        throw new Error(error.error || 'Verification failed');
      }
      
      const result = await response.json();
      
      // Success!
      setShowPreview(false);
      
      toast.success(`Successfully upgraded to ${newPlanName}!`, {
        description: result.flags?.wasReactivated 
          ? 'Your subscription has been reactivated!'
          : 'You now have access to all premium features.'
      });
      
      // Refresh page to show updated subscription
      router.refresh();
      
    } catch (error) {
      console.error('Verification error:', error);
      toast.error(error instanceof Error ? error.message : 'Upgrade verification failed');
    }
  };
  
  return (
    <>
      <Button
        variant={variant}
        size={size}
        className={className}
        onClick={handleUpgradeClick}
        disabled={isLoading}
      >
        {isLoading ? (
          <>
            <Loader2 className="h-4 w-4 mr-2 animate-spin" />
            Loading...
          </>
        ) : (
          <>
            <ArrowUp className="h-4 w-4 mr-2" />
            Upgrade to {newPlanName}
          </>
        )}
      </Button>
      
      <UpgradePreviewModal
        isOpen={showPreview}
        onClose={() => setShowPreview(false)}
        calculation={calculation}
        onConfirm={handleConfirmUpgrade}
      />
    </>
  );
}
```

```typescript
  paymentEntity: any
) {
  console.log('🎉 [WEBHOOK] Handling subscription.authenticated');

  // Check if this is an UPGRADE (subscription swap)
  const oldSubscriptionId = subscriptionEntity.notes?.oldSubscriptionId;
  const isUpgrade = subscriptionEntity.notes?.replacingSubscription === 'true';
  
  if (isUpgrade && oldSubscriptionId) {
    console.log('🔄 [WEBHOOK] This is an UPGRADE payment');
    console.log('   Old subscription:', oldSubscriptionId);
    console.log('   New subscription:', subscriptionEntity.id);
    
    // Find the OLD subscription record
    const oldDbSub = await prisma.subscription.findUnique({
      where: { razorpaySubscriptionId: oldSubscriptionId },
      include: { plan: true, user: true }
    });
    
    if (!oldDbSub) {
      console.error('❌ Old subscription not found for upgrade');
      // Still proceed with new subscription
    }
    
    await prisma.$transaction(async (tx) => {
      // STEP 1: NOW cancel old Razorpay subscription (payment successful!)
      if (oldDbSub?.razorpaySubscriptionId) {
        try {
          await razorpay.subscriptions.cancel(
            oldDbSub.razorpaySubscriptionId,
            false // Cancel immediately
          );
          console.log('✅ [WEBHOOK] Canceled old subscription after upgrade payment');
        } catch (error) {
          console.error('⚠️ [WEBHOOK] Failed to cancel old subscription:', error);
        }
      }
      
      // STEP 2: Get new plan details
      const newPlanId = subscriptionEntity.notes?.newPlanId;
      const newPlan = await tx.subscriptionPlan.findUnique({
        where: { id: newPlanId }
      });
      
      if (!newPlan) {
        throw new Error('New plan not found');
      }
      
      // STEP 3: Update OLD subscription record to point to NEW plan
      await tx.subscription.update({
        where: { id: oldDbSub.id },
        data: {
          planId: newPlan.id,
          razorpaySubscriptionId: subscriptionEntity.id, // New Razorpay sub ID
          razorpayPlanId: subscriptionEntity.plan_id,
          status: 'ACTIVE',
          billingCycle: newPlan.billingCycle,
          currentPeriodStart: new Date(subscriptionEntity.current_start * 1000),
          currentPeriodEnd: new Date(subscriptionEntity.current_end * 1000),
          nextChargeAt: new Date(subscriptionEntity.charge_at * 1000),
          paidCount: subscriptionEntity.paid_count,
          remainingCount: subscriptionEntity.remaining_count,
          autoRenew: true,
          updatedAt: new Date()
        }
      });
      
      // STEP 4: Create upgrade history
      await tx.subscriptionHistory.create({
        data: {
          subscriptionId: oldDbSub.id,
          action: 'UPGRADED',
          fromPlanId: oldDbSub.planId,
          toPlanId: newPlan.id,
          fromStatus: oldDbSub.status,
          toStatus: 'ACTIVE',
          reason: `Upgraded from ${oldDbSub.plan.displayName} to ${newPlan.displayName}`,
          metadata: {
            event: 'subscription.authenticated',
            upgradeType: 'immediate_with_proration',
            oldRazorpaySubId: oldSubscriptionId,
            newRazorpaySubId: subscriptionEntity.id,
            prorationCredit: subscriptionEntity.notes?.prorationCredit || 0
          }
        }
      });
      
      // STEP 5: Ensure user access
      await tx.user.update({
        where: { id: oldDbSub.userId },
        data: {
          isActive: true,
          gracePeriod: false
        }
      });
      
      // STEP 6: Create payment record
      if (paymentEntity) {
        await tx.payment.create({
          data: {
            userId: oldDbSub.userId,
            subscriptionId: oldDbSub.id,
            razorpayPaymentId: paymentEntity.id,
            razorpaySubscriptionId: subscriptionEntity.id,
            amountPaid: paymentEntity.amount / 100,
            subtotal: paymentEntity.amount / 100,
            currency: paymentEntity.currency.toUpperCase(),
            status: 'SUCCESS',
            paymentMethod: paymentEntity.method,
            description: `Upgrade payment - ${newPlan.displayName}`,
            paidAt: new Date(paymentEntity.created_at * 1000)
          }
        });
      }
    });
    
    console.log('✅ [WEBHOOK] Upgrade completed successfully');
    return;
  }
  
  // Regular subscription creation (not an upgrade)
  const dbSub = await prisma.subscription.findFirst({
    where: { razorpaySubscriptionId: subscriptionEntity.id },
    include: { plan: true, user: true }
  });
  
  if (!dbSub) {
    console.error('❌ Subscription not found in database');
    return NextResponse.json({ error: 'Subscription not found' }, { status: 404 });
  }
  
  await prisma.$transaction(async (tx) => {
    // Update subscription details
    await tx.subscription.update({
      where: { id: dbSub.id },
      data: {
        razorpaySubscriptionId: subscriptionEntity.id, // Update to new ID
        status: 'ACTIVE',
        paidCount: subscriptionEntity.paid_count,
        remainingCount: subscriptionEntity.remaining_count,
        nextChargeAt: new Date(subscriptionEntity.charge_at * 1000),
        currentPeriodStart: new Date(subscriptionEntity.current_start * 1000),
        currentPeriodEnd: new Date(subscriptionEntity.current_end * 1000),
        autoRenew: true,
        updatedAt: new Date()
      }
    });
    
    // Create history record
    if (isUpgrade) {
      await tx.subscriptionHistory.create({
        data: {
          subscriptionId: dbSub.id,
          action: 'UPGRADED',
          fromStatus: dbSub.status,
          toStatus: 'ACTIVE',
          reason: `Plan upgrade authenticated - New subscription ${subscriptionEntity.id}`,
          metadata: {
            event: 'subscription.authenticated',
            oldRazorpaySubId: replacedSubscriptionId,
            newRazorpaySubId: subscriptionEntity.id,
            upgradeType,
            webhookConfirmed: true
          }
        }
      });
    } else {
      // Regular subscription creation
      await tx.subscriptionHistory.create({
        data: {
          subscriptionId: dbSub.id,
          action: 'CREATED',
          fromStatus: dbSub.status,
          toStatus: 'ACTIVE',
          reason: 'Subscription authenticated - First payment successful',
          metadata: {
            event: 'subscription.authenticated',
            razorpaySubscriptionId: subscriptionEntity.id
          }
        }
      });
    }
    
    // Ensure user active
    await tx.user.update({
      where: { id: dbSub.userId },
      data: {
        isActive: true,
        gracePeriod: false
      }
    });
    
    // Restore store access
    await tx.store.updateMany({
      where: { userId: dbSub.userId },
      data: { isAccessible: true }
    });
  });
  
  console.log(`✅ [WEBHOOK] Subscription authenticated ${isUpgrade ? '(UPGRADE)' : ''}`);
}
```
