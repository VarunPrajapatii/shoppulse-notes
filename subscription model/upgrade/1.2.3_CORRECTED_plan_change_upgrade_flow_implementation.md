## Upgrade Scenarios Overview

### Scenario Matrix

| Current Status | Can Upgrade? | Method | Special Handling |
|----------------|--------------|--------|------------------|
| **ACTIVE** | ✅ Yes | UPDATE API | Standard flow |
| **AUTHENTICATED** | ✅ Yes | UPDATE API | Standard flow |
| **CANCELED** | ⚠️ Maybe | CREATE new | If scheduled cancellation |
| **COMPLETING** | ✅ Yes | UPDATE API | Extends beyond period end |
| **PAST_DUE** | ⚠️ Maybe | After payment | Must clear dues first |
| **EXPIRED** | ❌ No | CREATE new | Must create new subscription |
| **PAUSED** | ✅ Yes | UPDATE API | Can update while paused |
| **CREATED** | ❌ No | Wait | Must be authenticated first |

### Scenario 1: ACTIVE → Higher Tier (Standard Upgrade)

**Example**:
```
User: Monthly plan (₹3,500), Day 10 of 30
Wants: Half-Yearly plan (₹18,000)

Calculation (for display only):
- Days remaining: 20
- Unused value: ₹3,500 × (20/30) = ₹2,333.33
- Expected charge: ₹18,000 - ₹2,333.33 = ₹15,666.67
- New period: Today → Today + 180 days

Steps (OFFICIAL UPGRADE FLOW):
1. Show user preview of upgrade (calculated proration for display)
2. User confirms upgrade
3. Call UPDATE API:
   await razorpay.subscriptions.update(subscriptionId, {
     plan_id: halfYearlyPlanId,
     schedule_change_at: 'now',
     customer_notify: true
   })
4. Razorpay automatically:
   - Calculates proration (₹2,333.33)
   - Charges ₹15,666.67 to saved payment method
   - Updates plan to Half-Yearly
   - Fires subscription.updated webhook
5. In webhook: Update database with new plan
6. User gets immediate access to new limits ✓

BENEFITS:
✅ Same subscription ID (no disruption)
✅ Razorpay calculates proration (accurate)
✅ No checkout page (seamless)
✅ Simpler webhook (50 lines vs 163)
✅ No manual cancellation needed
```

### 1. Preview Upgrade (GET) - For Display Only

```typescript
// src/app/api/subscription/upgrade/preview/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';

export async function POST(req: Request) {
  try {
    const { userId } = await auth();
    if (!userId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }

    const { newPlanId } = await req.json();

    // Get current subscription
    const user = await prisma.user.findUnique({
      where: { id: userId },
      include: { 
        subscription: { 
          include: { plan: true } 
        } 
      }
    });

    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No active subscription' },
        { status: 404 }
      );
    }

    const currentSub = user.subscription;
    const newPlan = await prisma.subscriptionPlan.findUnique({
      where: { id: newPlanId }
    });

    if (!newPlan) {
      return NextResponse.json(
        { error: 'Plan not found' },
        { status: 404 }
      );
    }

    // Calculate proration FOR DISPLAY ONLY
    const now = new Date();
    const periodEnd = new Date(currentSub.currentPeriodEnd);
    const daysRemaining = Math.max(
      0,
      Math.ceil((periodEnd.getTime() - now.getTime()) / (1000 * 60 * 60 * 24))
    );

    const billingCycleDays = currentSub.billingCycle === 'MONTHLY' ? 30 :
                             currentSub.billingCycle === 'HALFYEARLY' ? 180 : 365;

    const credit = Number(currentSub.plan.price) * (daysRemaining / billingCycleDays);
    const expectedCharge = Math.max(0, Number(newPlan.price) - credit);

    return NextResponse.json({
      success: true,
      currentPlan: {
        id: currentSub.plan.id,
        name: currentSub.plan.name,
        price: Number(currentSub.plan.price),
        billingCycle: currentSub.billingCycle
      },
      newPlan: {
        id: newPlan.id,
        name: newPlan.name,
        price: Number(newPlan.price),
        billingCycle: newPlan.billingCycle
      },
      proration: {
        daysRemaining,
        credit: Math.round(credit * 100) / 100,
        expectedCharge: Math.round(expectedCharge * 100) / 100
      },
      note: 'These are estimates. Razorpay will calculate actual proration.'
    });

  } catch (error) {
    console.error('[UPGRADE_PREVIEW_ERROR]', error);
    return NextResponse.json(
      { error: 'Failed to preview upgrade' },
      { status: 500 }
    );
  }
}
```

### 2. Execute Upgrade (Official UPDATE API)

```typescript
// src/app/api/subscription/upgrade/execute/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';

export async function POST(req: Request) {
  try {
    const { userId } = await auth();
    if (!userId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }

    const { newPlanId, applyImmediately = true } = await req.json();

    // Get current subscription
    const user = await prisma.user.findUnique({
      where: { id: userId },
      include: { subscription: { include: { plan: true } } }
    });

    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No active subscription' },
        { status: 404 }
      );
    }

    const currentSub = user.subscription;

    // Validate subscription status
    if (!['ACTIVE', 'AUTHENTICATED'].includes(currentSub.status)) {
      return NextResponse.json(
        { 
          error: 'Subscription must be active to upgrade',
          currentStatus: currentSub.status
        },
        { status: 400 }
      );
    }

    // Get new plan
    const newPlan = await prisma.subscriptionPlan.findUnique({
      where: { id: newPlanId }
    });

    if (!newPlan) {
      return NextResponse.json(
        { error: 'Plan not found' },
        { status: 404 }
      );
    }

    // Validate upgrade (must be higher price)
    if (Number(newPlan.price) <= Number(currentSub.plan.price)) {
      return NextResponse.json(
        { error: 'New plan must be more expensive (use downgrade endpoint)' },
        { status: 400 }
      );
    }

    // ✅ CALL OFFICIAL UPDATE API
    const updatedSubscription = await razorpay.subscriptions.update(
      currentSub.razorpaySubscriptionId!,
      {
        plan_id: newPlan.razorpayPlanId!,
        schedule_change_at: applyImmediately ? 'now' : 'cycle_end',
        customer_notify: true
      }
    );

    console.log('[UPGRADE] Razorpay subscription updated:', updatedSubscription.id);

    // Update database (webhook will complete the update, but we can update some fields now)
    await prisma.subscription.update({
      where: { id: currentSub.id },
      data: {
        hasScheduledChanges: updatedSubscription.has_scheduled_changes || false,
        scheduledPlanId: applyImmediately ? null : newPlanId,
        changeScheduledAt: updatedSubscription.change_scheduled_at 
          ? new Date(updatedSubscription.change_scheduled_at * 1000)
          : null,
        metadata: {
          lastUpgradeAttempt: new Date().toISOString(),
          upgradeMethod: 'UPDATE_API'
        }
      }
    });

    // Create history record
    await prisma.subscriptionHistory.create({
      data: {
        subscriptionId: currentSub.id,
        action: 'UPGRADED',
        fromPlanId: currentSub.planId,
        toPlanId: newPlanId,
        method: 'UPDATE_API',
        metadata: {
          applyImmediately,
          razorpaySubscriptionId: updatedSubscription.id,
          hasScheduledChanges: updatedSubscription.has_scheduled_changes
        }
      }
    });

    return NextResponse.json({
      success: true,
      message: applyImmediately 
        ? 'Upgrade processed successfully! Your plan has been updated.'
        : 'Upgrade scheduled for next billing cycle.',
      subscription: {
        id: updatedSubscription.id,
        planId: applyImmediately ? newPlan.razorpayPlanId : currentSub.plan.razorpayPlanId,
        hasScheduledChanges: updatedSubscription.has_scheduled_changes,
        changeScheduledAt: updatedSubscription.change_scheduled_at
      }
    });

  } catch (error: any) {
    console.error('[UPGRADE_EXECUTE_ERROR]', error);
    
    // Handle specific Razorpay errors
    if (error.error?.code === 'BAD_REQUEST_ERROR') {
      return NextResponse.json(
        { 
          error: error.error.description,
          code: error.error.code
        },
        { status: 400 }
      );
    }

    return NextResponse.json(
      { error: 'Failed to upgrade subscription' },
      { status: 500 }
    );
  }
}
```

```typescript
// src/app/api/webhook/razorpay/subscription/route.ts

async function handleSubscriptionUpdated(subscriptionEntity: any) {
  console.log('🔄 [WEBHOOK] subscription.updated received');
  
  const razorpaySubId = subscriptionEntity.id;
  
  // Find subscription in database
  const dbSub = await prisma.subscription.findUnique({
    where: { razorpaySubscriptionId: razorpaySubId },
    include: { plan: true, user: true }
  });

  if (!dbSub) {
    console.error('[WEBHOOK] Subscription not found:', razorpaySubId);
    return;
  }

  // Get new plan ID from Razorpay
  const newRazorpayPlanId = subscriptionEntity.plan_id;
  
  // Find new plan in database
  const newPlan = await prisma.subscriptionPlan.findUnique({
    where: { razorpayPlanId: newRazorpayPlanId }
  });

  if (!newPlan) {
    console.error('[WEBHOOK] New plan not found:', newRazorpayPlanId);
    return;
  }

  // Check if plan actually changed
  if (dbSub.planId === newPlan.id) {
    console.log('[WEBHOOK] Plan unchanged, skipping update');
    return;
  }

  console.log(`[WEBHOOK] Plan changed: ${dbSub.plan.name} → ${newPlan.name}`);

  // Update subscription
  await prisma.subscription.update({
    where: { id: dbSub.id },
    data: {
      planId: newPlan.id,
      razorpayPlanId: newRazorpayPlanId,
      billingCycle: newPlan.billingCycle,
      status: 'ACTIVE',
      currentPeriodStart: new Date(subscriptionEntity.current_start * 1000),
      currentPeriodEnd: new Date(subscriptionEntity.current_end * 1000),
      paidCount: subscriptionEntity.paid_count || 0,
      remainingCount: subscriptionEntity.remaining_count,
      hasScheduledChanges: subscriptionEntity.has_scheduled_changes || false,
      scheduledPlanId: null,
      changeScheduledAt: null,
      canceledAt: null, // Clear cancellation if was cancelled
      cancelAtPeriodEnd: false,
      autoRenew: true
    }
  });

  // Create history
  await prisma.subscriptionHistory.create({
    data: {
      subscriptionId: dbSub.id,
      action: 'PLAN_CHANGED',
      fromStatus: dbSub.status,
      toStatus: 'ACTIVE',
      fromPlanId: dbSub.planId,
      toPlanId: newPlan.id,
      metadata: {
        source: 'subscription.updated_webhook',
        razorpaySubscriptionId: razorpaySubId,
        paidCount: subscriptionEntity.paid_count
      }
    }
  });

  // Invalidate cache
  await invalidateStoreCache(dbSub.user.storeId);

  console.log(`✅ [WEBHOOK] Subscription updated: ${dbSub.plan.name} → ${newPlan.name}`);
}

// Main webhook handler
export async function POST(req: Request) {
  try {
    const body = await req.json();
    const event = body.event;

    console.log('[WEBHOOK] Received event:', event);

    // Verify signature
    const signature = req.headers.get('x-razorpay-signature');
    if (!verifyWebhookSignature(body, signature)) {
      return NextResponse.json({ error: 'Invalid signature' }, { status: 400 });
    }

    // Handle different events
    switch (event) {
      case 'subscription.authenticated':
        await handleSubscriptionAuthenticated(body.payload.subscription);
        break;
        
      case 'subscription.activated':
        await handleSubscriptionActivated(body.payload.subscription);
        break;
        
      case 'subscription.charged':
        await handleSubscriptionCharged(body.payload.subscription, body.payload.payment);
        break;
        
      case 'subscription.updated':
        await handleSubscriptionUpdated(body.payload.subscription.entity);
        break;
        
      case 'subscription.cancelled':
        await handleSubscriptionCancelled(body.payload.subscription);
        break;
        
      default:
        console.log('[WEBHOOK] Unhandled event:', event);
    }

    return NextResponse.json({ success: true });

  } catch (error) {
    console.error('[WEBHOOK_ERROR]', error);
    return NextResponse.json({ error: 'Webhook processing failed' }, { status: 500 });
  }
}
```

```typescript
import { useState } from 'react';
import { useRouter } from 'next/navigation';
import { toast } from 'sonner';
import { Button } from '@/components/ui/button';
import { Loader2, ArrowUp, Check } from 'lucide-react';
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
} from '@/components/ui/dialog';

interface UpgradeButtonProps {
  currentPlan: {
    id: string;
    name: string;
    price: number;
  };
  newPlan: {
    id: string;
    name: string;
    price: number;
  };
  disabled?: boolean;
}

export function UpgradeButton({ currentPlan, newPlan, disabled }: UpgradeButtonProps) {
  const router = useRouter();
  const [isOpen, setIsOpen] = useState(false);
  const [isLoading, setIsLoading] = useState(false);
  const [preview, setPreview] = useState<any>(null);

  // Fetch preview when dialog opens
  const handleOpenDialog = async () => {
    setIsOpen(true);
    setIsLoading(true);

    try {
      const response = await fetch('/api/subscription/upgrade/preview', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ newPlanId: newPlan.id })
      });

      if (!response.ok) throw new Error('Failed to fetch preview');

      const data = await response.json();
      setPreview(data);
    } catch (error) {
      toast.error('Failed to load upgrade preview');
      setIsOpen(false);
    } finally {
      setIsLoading(false);
    }
  };

  // Execute upgrade
  const handleConfirmUpgrade = async () => {
    setIsLoading(true);

    try {
      const response = await fetch('/api/subscription/upgrade/execute', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          newPlanId: newPlan.id,
          applyImmediately: true
        })
      });

        const error = await response.json();
        throw new Error(error.error || 'Upgrade failed');

      const data = await response.json();

        description: 'Your plan has been updated. New features are now available.'
      });

      setIsOpen(false);
      router.refresh();

      toast.error(error.message || 'Upgrade failed');

      setIsLoading(false);
    }

            <DialogDescription>
              Upgrade from {currentPlan.name} to {newPlan.name}
            </DialogDescription>
          </DialogHeader>

            <div className="flex items-center justify-center py-8">
              <Loader2 className="h-8 w-8 animate-spin" />
            </div>
          ) : preview ? (
            <div className="space-y-4">
              {/* Current Plan */}
              <div className="flex items-center justify-between p-4 border rounded-lg">
                <div>
                  <p className="font-medium">{preview.currentPlan.name}</p>
                  <p className="text-sm text-muted-foreground">Current Plan</p>
                </div>
                <p className="text-lg font-bold">₹{preview.currentPlan.price}</p>
              </div>

              {/* Arrow */}

                <p className="text-lg font-bold text-primary">₹{preview.newPlan.price}</p>
```


### User Journey (Upgrade)

```

   ├─> API call: POST /api/subscription/upgrade/execute
   ├─> Validates subscription status

   │   razorpay.subscriptions.update(subId, {

   │   ├─ planId: monthly → halfyearly

   ├─> Sees success message: "Upgrade successful!"
   ├─> Page refreshes
   ├─> Dashboard shows: Half-Yearly plan
   ├─> New limits immediately available
   └─> No checkout page needed ✓

Benefits:
✅ Seamless (no checkout)

✅ Accurate (Razorpay calculates)
```
