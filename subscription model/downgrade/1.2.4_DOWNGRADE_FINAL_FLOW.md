## Overview

### Approach: Grace Period Method (Recommended) ⭐

**Key Principles**:
- ✅ User keeps full plan features until paid period ends
- ✅ Downgrade scheduled at cycle end using Razorpay UPDATE API
- ✅ After downgrade applies, 5-day grace period activates if usage exceeds limits
- ✅ Auto-archive (not archive, delete) oldest products after grace period
- ✅ Same subscription ID throughout
- ✅ No refund/credit complexity

**Industry Standard**: Netflix, Spotify, Shopify, Heroku, AWS all use this approach

## Downgrade Strategy

### Why Grace Period?

**Problem Scenario**:
```
Half-Yearly Plan: 100 products, ₹18,000
Current usage: 90 products
Time: 2 months into plan (4 months remaining)
Want to downgrade to: Monthly Plan (50 products, ₹3,500)

Without Grace Period ❌:
- Force user to delete 40 products NOW
- User paid for 100 products for 4 more months!
- Loses business value mid-cycle

With Grace Period ✅:
- Schedule downgrade anytime (no cleanup required)
- User keeps 90 products until paid period ends
- After downgrade: 5-day grace period to reduce from 90 → 50
- Auto-archive (EDIT: delete, not archive) 40 oldest products if user doesn't act
- User can review and restore important ones
```

### Flow Overview

```
User wants to downgrade
  ↓
Schedule downgrade (NO usage validation blocking)
  ↓
Call UPDATE API with schedule_change_at: 'cycle_end'
  ↓
Razorpay stores scheduled change
  ↓
User keeps current plan features (no immediate change) also before 7 days of period end we tell user to start getting under limits via dashboard notifications and email
  ↓
At cycle end: Razorpay applies change automatically
  ↓
subscription.updated webhook fires
  ↓
Check: Does usage exceed new limits?
  ↓
  ├─ NO  → Normal downgrade (update DB, from now the usage flow will work normal as it should be working for the new implemented plan)
  │
  └─ YES → Activate 5-day grace period
            ↓
            Update subscription metadata with grace info
            ↓
            Send grace period activation email
            ↓
            Show dashboard banner with countdown
            ↓
            Send reminder emails (everyday)
            ↓
            Day 5: Cron job auto-archives (EDIT: delete, not archive) excess products, and metrics
            ↓
            Archive (EDIT: delete) 40 oldest products (by createdAt DESC)
            ↓
            Send notification with archived products list
            ↓
            User can restore important products manually
            ↓
            System enforces 50 product limit ✓
```

## Grace Period System

### Timeline Example

**Month 2**: Schedule downgrade
- User has 90 products
- Schedules downgrade to 50-product plan
- No cleanup required ✅

**Months 3-6**: User keeps PRO features
- Still has 90 products active
- Using paid subscription value ✅
- EDIT: 6th month, last 7 days, we recommend/warn user to get under limits else after plan comes in effective, we will auto delete the products and other metrics. we notify via in app notification and email.

**Month 6 (Period End)**: Downgrade applied
- subscription.updated webhook fires
- System checks: 90 > 50 → Overage detected
- Grace period activated: 5 days

**Grace Period (5 days)**:
- Day 1: Email sent ("You have 4 days to reduce products")
- Day 2: Reminder email ("3 days remaining")
- Day 3: Urgent reminder ("2 days remaining")
- Day 4: Final warning ("Tomorrow products will be archived (EDIT: deleted)")
- Dashboard shows countdown banner throughout

**Day 5**: Auto-archive (EDIT: auto-delete) enforcement
- Cron job runs daily at midnight
- Detects expired grace period
- Selects 40 products to archive (EDIT: delete)
- Sends email with archived (EDIT: deleted) products list in a pdf

### Archive Reasons (EDIT: NOT OF USE, as we delete not archive)

Three types of archiving:

1. **`manual`**: User archived via dashboard
2. **`out_of_stock`**: Auto-archived when stock reaches 0
3. **`plan_downgrade`**: Force-archived due to plan limits

```typescript
// src/lib/downgrade-validator.ts

import prisma from '@/lib/prismadb';

export async function getCurrentUsage(userId: string): Promise<{
  products: number;
  orders: number;
  storageGB: number;
  categories: number;
  billboards: number;
}> {
  const store = await prisma.store.findFirst({
    where: { userId },
    select: { id: true }
  });
  
  if (!store) {
    return {
      products: 0,
      orders: 0,
      storageGB: 0,
      categories: 0,
      billboards: 0
    };
  }
  
  // Count ONLY active products (not archived)
  const productsCount = await prisma.product.count({
    where: { storeId: store.id, isArchived: false }
  });
  
  const ordersCount = await prisma.order.count({
    where: { storeId: store.id }
  });
  
  const categoriesCount = await prisma.category.count({
    where: { storeId: store.id }
  });
  
  const billboardsCount = await prisma.billboard.count({
    where: { storeId: store.id }
  });
  
  // Calculate storage (simplified)
  const images = await prisma.image.findMany({
    where: {
      product: { storeId: store.id }
    }
  });
  
  // Estimate 500KB per image
  const storageGB = (images.length * 0.5) / 1024; // MB to GB
  
  return {
    products: productsCount,
    orders: ordersCount,
    storageGB: Math.round(storageGB * 100) / 100,
    categories: categoriesCount,
    billboards: billboardsCount
  };
}
```

### Endpoint 1: Schedule Downgrade

```typescript
// src/app/api/subscription/downgrade/schedule/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';
import { getCurrentUsage } from '@/lib/downgrade-validator';
import { differenceInDays } from 'date-fns';

export async function POST(req: Request) {
  try {
    const { userId } = await auth();
    if (!userId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const { newPlanId } = await req.json();
    
    // Get user's current subscription
    const user = await prisma.user.findUnique({
      where: { id: userId },
      include: {
        subscription: {
          include: { plan: true }
        }
      }
    });
    
    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No active subscription found' },
        { status: 400 }
      );
    }
    
    const currentSub = user.subscription;
    
    // Validate subscription status
    if (!['ACTIVE', 'AUTHENTICATED'].includes(currentSub.status)) {
      return NextResponse.json(
        { 
          error: `Cannot downgrade ${currentSub.status.toLowerCase()} subscription`,
          currentStatus: currentSub.status 
        },
        { status: 400 }
      );
    }
    
    // Get new plan
    const newPlan = await prisma.subscriptionPlan.findUnique({
      where: { id: newPlanId }
    });
    
    if (!newPlan) {
      return NextResponse.json({ error: 'Plan not found' }, { status: 404 });
    }
    
    // Validate it's a downgrade (lower price)
    const currentPrice = Number(currentSub.plan.price);
    const newPrice = Number(newPlan.price);
    
    if (newPrice >= currentPrice) {
      return NextResponse.json({
        error: 'New plan must be less expensive. Use upgrade endpoint for more expensive plans.'
      }, { status: 400 });
    }
    
    // Get current usage (for info only, NOT blocking)
    const usage = await getCurrentUsage(userId);
    const willExceedLimits = usage.products > (newPlan.maxProducts || Infinity);
    
    if (willExceedLimits) {
      console.log(`⚠️ User will exceed limits after downgrade`);
      console.log(`   Current: ${usage.products} | New limit: ${newPlan.maxProducts}`);
      // Log it, but allow scheduling (grace period will handle it)
    }
    
    // Calculate days until change
    const daysUntilChange = Math.max(
      0,
      differenceInDays(currentSub.currentPeriodEnd, new Date())
    );
    
    console.log(`[DOWNGRADE] Scheduling downgrade for ${user.email}`);
    console.log(`[DOWNGRADE] ${currentSub.plan.name} → ${newPlan.name}`);
    console.log(`[DOWNGRADE] Days until change: ${daysUntilChange}`);
    
    // ✅ CALL RAZORPAY UPDATE API WITH SCHEDULE
    const updatedSubscription = await razorpay.subscriptions.update(
      currentSub.razorpaySubscriptionId!,
      {
        plan_id: newPlan.razorpayPlanId!,
        schedule_change_at: 'cycle_end',
        customer_notify: true
      }
    );
    
    console.log('[DOWNGRADE] Scheduled in Razorpay successfully');
    
    // Update database with scheduled change metadata
    await prisma.subscription.update({
      where: { id: currentSub.id },
      data: {
        hasScheduledChanges: updatedSubscription.has_scheduled_changes || false,
        scheduledPlanId: newPlanId,
        changeScheduledAt: updatedSubscription.change_scheduled_at
          ? new Date(updatedSubscription.change_scheduled_at * 1000)
          : null,
        metadata: {
          ...((currentSub.metadata as any) || {}),
          lastDowngradeAttempt: new Date().toISOString(),
          downgradeMethod: 'UPDATE_API_SCHEDULED',
          scheduledDowngrade: {
            willExceedLimits,
            currentUsage: usage,
            newLimits: {
              products: newPlan.maxProducts,
              categories: newPlan.maxCategories,
              billboards: newPlan.maxBillboards,
              storageGB: newPlan.maxStorageGB
            }
          }
        }
      }
    });
    
    // Create history record
    await prisma.subscriptionHistory.create({
      data: {
        subscriptionId: currentSub.id,
        action: 'DOWNGRADED',
        fromPlanId: currentSub.planId,
        toPlanId: newPlanId,
        fromStatus: currentSub.status,
        toStatus: currentSub.status,
        reason: 'Scheduled downgrade via UPDATE API',
        metadata: {
          method: 'UPDATE_API',
          scheduleType: 'cycle_end',
          effectiveDate: currentSub.currentPeriodEnd,
          daysUntilChange,
          oldPlanPrice: currentPrice,
          newPlanPrice: newPrice,
          savingsPerCycle: currentPrice - newPrice,
          willExceedLimits
        }
      }
    });
    
    console.log(`✅ [DOWNGRADE] Scheduled successfully`);
    
    return NextResponse.json({
      success: true,
      message: 'Downgrade scheduled successfully',
      details: {
        currentPlan: currentSub.plan.displayName,
        newPlan: newPlan.displayName,
        effectiveDate: currentSub.currentPeriodEnd,
        daysUntilChange,
        currentPrice,
        newPrice,
        savingsPerCycle: currentPrice - newPrice,
        graceInfo: willExceedLimits ? {
          gracePeriodDays: 5,
          currentUsage: usage.products,
          newLimit: newPlan.maxProducts,
          excessCount: usage.products - (newPlan.maxProducts || 0),
          message: `You'll have 5 days after ${currentSub.currentPeriodEnd.toLocaleDateString()} to reduce from ${usage.products} to ${newPlan.maxProducts} products`
        } : null
      }
    });
    
  } catch (error: any) {
    console.error('[DOWNGRADE_SCHEDULE_ERROR]', error);
    
    if (error.error?.code === 'BAD_REQUEST_ERROR') {
      return NextResponse.json(
        {
          error: error.error.description || 'Invalid request to Razorpay',
          code: error.error.code
        },
        { status: 400 }
      );
    }
    
    return NextResponse.json(
      { error: 'Failed to schedule downgrade' },
      { status: 500 }
    );
  }
}
```

### Endpoint 2: Cancel Scheduled Downgrade

```typescript
// src/app/api/subscription/downgrade/cancel-scheduled/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';

export async function POST(req: Request) {
  try {
    const { userId } = await auth();
    if (!userId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const user = await prisma.user.findUnique({
      where: { id: userId },
      include: {
        subscription: {
          include: { plan: true }
        }
      }
    });
    
    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No subscription found' },
        { status: 400 }
      );
    }
    
    const subscription = user.subscription;
    
    if (!subscription.hasScheduledChanges) {
      return NextResponse.json(
        { error: 'No scheduled downgrade found' },
        { status: 400 }
      );
    }
    
    console.log(`[DOWNGRADE] Canceling scheduled downgrade for ${user.email}`);
    
    // Cancel in Razorpay
    try {
      await razorpay.subscriptions.cancelScheduledChanges(
        subscription.razorpaySubscriptionId!
      );
      console.log('✅ [DOWNGRADE] Canceled in Razorpay successfully');
    } catch (error) {
      console.warn('⚠️ [DOWNGRADE] Failed to cancel in Razorpay:', error);
    }
    
    // Update database
    await prisma.$transaction(async (tx) => {
      await tx.subscription.update({
        where: { id: subscription.id },
        data: {
          hasScheduledChanges: false,
          scheduledPlanId: null,
          changeScheduledAt: null,
          metadata: {
            ...((subscription.metadata as any) || {}),
            canceledScheduledDowngrade: {
              canceledAt: new Date().toISOString(),
              canceledPlanId: subscription.scheduledPlanId,
              reason: 'User canceled scheduled downgrade'
            }
          },
          updatedAt: new Date()
        }
      });
      
      await tx.subscriptionHistory.create({
        data: {
          subscriptionId: subscription.id,
          action: 'REACTIVATED',
          reason: 'Canceled scheduled downgrade',
          metadata: {
            canceledScheduledPlanId: subscription.scheduledPlanId,
            canceledAt: new Date()
          }
        }
      });
    });
    
    console.log(`✅ [DOWNGRADE] Canceled successfully`);
    
    return NextResponse.json({
      success: true,
      message: 'Scheduled downgrade canceled successfully',
      currentPlan: subscription.plan.displayName
    });
    
  } catch (error) {
    console.error('[DOWNGRADE_CANCEL_ERROR]', error);
    return NextResponse.json(
      { error: 'Failed to cancel scheduled downgrade' },
      { status: 500 }
    );
  }
}
```

```typescript
// src/app/api/webhook/razorpay/subscription/route.ts

import { NextResponse } from 'next/server';
import prisma from '@/lib/prismadb';
import { getCurrentUsage } from '@/lib/downgrade-validator';

async function handleSubscriptionUpdated(subscriptionEntity: any) {
  console.log('🔄 [WEBHOOK] subscription.updated received');
  
  const razorpaySubId = subscriptionEntity.id;
  
  // Find subscription in database
  const dbSub = await prisma.subscription.findUnique({
    where: { razorpaySubscriptionId: razorpaySubId },
    include: { plan: true, user: true }
  });
  
  if (!dbSub) {
    console.error('[WEBHOOK] Subscription not found:', razorpaySubId);
    return;
  }
  
  // Get new plan from Razorpay response
  const newRazorpayPlanId = subscriptionEntity.plan_id;
  
  // Find new plan in database
  const newPlan = await prisma.subscriptionPlan.findUnique({
    where: { razorpayPlanId: newRazorpayPlanId }
  });
  
  if (!newPlan) {
    console.error('[WEBHOOK] New plan not found:', newRazorpayPlanId);
    return;
  }
  
  // Check if plan actually changed
  if (dbSub.planId === newPlan.id) {
    console.log('[WEBHOOK] Plan unchanged, skipping');
    return;
  }
  
  const isDowngrade = Number(newPlan.price) < Number(dbSub.plan.price);
  console.log(`[WEBHOOK] ${isDowngrade ? 'DOWNGRADE' : 'UPGRADE'}: ${dbSub.plan.name} → ${newPlan.name}`);
  
  if (isDowngrade) {
    // Check current usage vs new limits
    const usage = await getCurrentUsage(dbSub.userId);
    const overLimit = newPlan.maxProducts !== null && usage.products > newPlan.maxProducts;
    
    if (overLimit) {
      console.log(`⚠️ [WEBHOOK] Usage exceeds limits: ${usage.products} > ${newPlan.maxProducts}`);
      
      // Activate grace period (5 days)
      const gracePeriodEnd = new Date();
      gracePeriodEnd.setDate(gracePeriodEnd.getDate() + 5);
      
      await prisma.subscription.update({
        where: { id: dbSub.id },
        data: {
          planId: newPlan.id,
          razorpayPlanId: newRazorpayPlanId,
          billingCycle: newPlan.billingCycle,
          status: 'ACTIVE',
          currentPeriodStart: new Date(subscriptionEntity.current_start * 1000),
          currentPeriodEnd: new Date(subscriptionEntity.current_end * 1000),
          paidCount: subscriptionEntity.paid_count || 0,
          remainingCount: subscriptionEntity.remaining_count,
          hasScheduledChanges: false,
          scheduledPlanId: null,
          changeScheduledAt: null,
          metadata: {
            ...((dbSub.metadata as any) || {}),
            gracePeriod: {
              active: true,
              startDate: new Date().toISOString(),
              endDate: gracePeriodEnd.toISOString(),
              currentUsage: usage.products,
              targetLimit: newPlan.maxProducts,
              excessCount: usage.products - newPlan.maxProducts
            },
            lastWebhookUpdate: new Date().toISOString(),
            webhookEvent: 'subscription.updated',
            changeType: 'downgrade_with_grace_period'
          }
        }
      });
      
      // Send grace period activation email
      await sendGracePeriodEmail({
        email: dbSub.user.email,
        userName: dbSub.user.name || 'User',
        gracePeriodEnd,
        currentUsage: usage.products,
        newLimit: newPlan.maxProducts!,
        excessCount: usage.products - newPlan.maxProducts!,
        planName: newPlan.displayName
      });
      
      console.log(`✅ [WEBHOOK] Grace period activated until ${gracePeriodEnd.toLocaleDateString()}`);
      
    } else {
      // No overage - normal downgrade
      await prisma.subscription.update({
        where: { id: dbSub.id },
        data: {
          planId: newPlan.id,
          razorpayPlanId: newRazorpayPlanId,
          billingCycle: newPlan.billingCycle,
          status: 'ACTIVE',
          currentPeriodStart: new Date(subscriptionEntity.current_start * 1000),
          currentPeriodEnd: new Date(subscriptionEntity.current_end * 1000),
          paidCount: subscriptionEntity.paid_count || 0,
          remainingCount: subscriptionEntity.remaining_count,
          hasScheduledChanges: false,
          scheduledPlanId: null,
          changeScheduledAt: null
        }
      });
      
      console.log(`✅ [WEBHOOK] Downgrade completed (no overage)`);
    }
  } else {
    // Handle upgrade (existing logic)
    await prisma.subscription.update({
      where: { id: dbSub.id },
      data: {
        planId: newPlan.id,
        razorpayPlanId: newRazorpayPlanId,
        billingCycle: newPlan.billingCycle,
        status: 'ACTIVE',
        currentPeriodStart: new Date(subscriptionEntity.current_start * 1000),
        currentPeriodEnd: new Date(subscriptionEntity.current_end * 1000),
        paidCount: subscriptionEntity.paid_count || 0,
        remainingCount: subscriptionEntity.remaining_count,
        hasScheduledChanges: false,
        scheduledPlanId: null,
        changeScheduledAt: null
      }
    });
    
    console.log(`✅ [WEBHOOK] Upgrade completed`);
  }
  
  // Create history record
  await prisma.subscriptionHistory.create({
    data: {
      subscriptionId: dbSub.id,
      action: isDowngrade ? 'DOWNGRADED' : 'UPGRADED',
      fromPlanId: dbSub.planId,
      toPlanId: newPlan.id,
      fromStatus: dbSub.status,
      toStatus: 'ACTIVE',
      reason: `Plan changed via subscription.updated webhook`,
      metadata: {
        source: 'webhook',
        event: 'subscription.updated',
        changeType: isDowngrade ? 'downgrade' : 'upgrade',
        priceChange: Number(newPlan.price) - Number(dbSub.plan.price)
      }
    }
  });
  
  console.log(`✅ [WEBHOOK] Subscription ${isDowngrade ? 'downgraded' : 'upgraded'} successfully`);
}

export async function POST(req: Request) {
  try {
    const body = await req.json();

      console.error('[WEBHOOK] Invalid signature');
      return NextResponse.json({ error: 'Invalid signature' }, { status: 400 });

    switch (event) {
      case 'subscription.authenticated':
        await handleSubscriptionAuthenticated(
          body.payload.subscription.entity,

        await handleSubscriptionCancelled(body.payload.subscription.entity);
        break;
      
      default:
        console.log('[WEBHOOK] Unhandled event:', event);
    }
    
    return NextResponse.json({ success: true });
    
  } catch (error) {
    console.error('[WEBHOOK_ERROR]', error);
    return NextResponse.json(
      { error: 'Webhook processing failed' },
      { status: 500 }
    );
  }
}
```

## Cron Job: Grace Period Enforcement

### Daily Check for Expired Grace Periods

```typescript
// src/app/api/cron/enforce-grace-periods/route.ts

import { NextResponse } from 'next/server';
import prisma from '@/lib/prismadb';

export async function GET(req: Request) {
  try {
    // Verify cron secret
    const authHeader = req.headers.get('authorization');
    if (authHeader !== `Bearer ${process.env.CRON_SECRET}`) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const now = new Date();
    console.log(`[CRON] Checking grace periods at ${now.toISOString()}`);
    
    // Find subscriptions with active grace periods
    const subscriptions = await prisma.subscription.findMany({
      where: {
        metadata: {
          path: ['gracePeriod', 'active'],
          equals: true
        }
      },
      include: { user: true, plan: true }
    });
    
    console.log(`[CRON] Found ${subscriptions.length} subscriptions with grace periods`);
    
    let enforcedCount = 0;
    let remindersSent = 0;
    
    for (const sub of subscriptions) {
      const gracePeriod = (sub.metadata as any)?.gracePeriod;
      if (!gracePeriod) continue;
      
      const gracePeriodEnd = new Date(gracePeriod.endDate);
      
      // Check if grace period expired
      if (now > gracePeriodEnd) {
        console.log(`⚠️ [CRON] Enforcing limits for ${sub.user.email}`);
        
        // Enforce product limit
        await enforceProductLimit(
          sub.user.id,
          sub.plan.maxProducts,
          gracePeriod.excessCount
        );
        
        // Clear grace period
        await prisma.subscription.update({
          where: { id: sub.id },
          data: {
            metadata: {
              ...((sub.metadata as any) || {}),
              gracePeriod: {
                ...gracePeriod,
                active: false,
                enforcedAt: new Date().toISOString()
              }
            }
          }
        });
        
        enforcedCount++;
        
      } else {
        // Send reminder emails at intervals
        const daysRemaining = Math.ceil(
          (gracePeriodEnd.getTime() - now.getTime()) / (1000 * 60 * 60 * 24)
        );
        
        if ([7, 3, 1].includes(daysRemaining)) {
          await sendGracePeriodReminder({
            email: sub.user.email,
            userName: sub.user.name || 'User',
            daysRemaining,
            currentUsage: gracePeriod.currentUsage,
            targetLimit: gracePeriod.targetLimit,
            excessCount: gracePeriod.excessCount
          });
          remindersSent++;
        }
      }
    }
    
    console.log(`✅ [CRON] Enforced: ${enforcedCount}, Reminders: ${remindersSent}`);
    
    return NextResponse.json({
      success: true,
      enforcedCount,
      remindersSent,
      totalChecked: subscriptions.length
    });
    
  } catch (error) {
    console.error('[CRON_ERROR]', error);
    return NextResponse.json(
      { error: 'Grace period enforcement failed' },
      { status: 500 }
    );
  }
}

async function enforceProductLimit(
  userId: string,
  maxProducts: number | null,
  excessCount: number
) {
  if (maxProducts === null) return; // Unlimited plan
  
  const store = await prisma.store.findFirst({
    where: { userId },
    select: { id: true }
  });
  
  if (!store) return;
  
  // Get all active products sorted by CREATION DATE (oldest first)
  // Latest products are kept, oldest are archived
  const products = await prisma.product.findMany({
    where: { 
      storeId: store.id, 
      isArchived: false 
    },
    orderBy: {
      createdAt: 'desc'  // DESC: Latest first (we'll archive from the end)
    }
  });
  
  // If under limit, nothing to do
  if (products.length <= maxProducts) {
    console.log(`✅ User within limit (${products.length}/${maxProducts})`);
    return;
  }
  
  // Archive oldest products (take from end of DESC sorted array)
  const productsToKeep = products.slice(0, maxProducts);
  const productsToArchive = products.slice(maxProducts);
  const archiveIds = productsToArchive.map(p => p.id);
  
  console.log(`📦 [CRON] Archiving ${archiveIds.length} oldest products`);
  console.log(`   Keeping latest ${productsToKeep.length} products`);
  
  await prisma.product.updateMany({
    where: { id: { in: archiveIds } },
    data: { 
      isArchived: true,
      archivedReason: 'plan_downgrade',
      archivedAt: new Date()
    }
  });
  
  // Send notification with archived products list
  await sendProductsArchivedEmail({
    userId,
    archivedCount: archiveIds.length,
    archivedProducts: productsToArchive.map(p => ({
      id: p.id,
      name: p.name,
      createdAt: p.createdAt
    }))
  });
  
  console.log(`✅ [CRON] Auto-archived ${archiveIds.length} products`);
}
```

## Why Store Metadata?

### Question: Why track `lastDowngradeAttempt` and `downgradeMethod`?

**Answer**: Debugging, analytics, and audit trails

#### Use Cases:

**1. Debugging Support Issues**
```typescript
// Customer: "I tried to downgrade but it didn't work"
// Support checks metadata:
{
  lastDowngradeAttempt: "2025-11-20T10:30:00Z",  // When they tried
  downgradeMethod: "UPDATE_API_SCHEDULED",        // How we processed it
  scheduledDowngrade: {
    willExceedLimits: true,                       // Why grace period activated
    currentUsage: { products: 90 },
    newLimits: { products: 50 }
  }
}
// Support can see exactly what happened and when
```

**2. Analytics & Business Intelligence**
```typescript
// Questions we can answer:
// - How many users schedule downgrades but cancel them?
// - What's the average time between scheduling and effective date?
// - Do users who exceed limits keep their subscriptions longer?
// - Are downgrades seasonal?

const downgradeAnalytics = await prisma.subscription.findMany({
  where: {
    metadata: {
      path: ['lastDowngradeAttempt'],
      not: null
    }
  }
});
```

**3. Fraud Detection**
```typescript
// NOTE: this is important to implement
// Detect suspicious patterns:
// - User downgrades/upgrades 10 times in a day
// - User schedules downgrade, immediately cancels, repeats

const suspiciousActivity = metadata.downgradeHistory?.length > 5;
```

**4. Feature Flag Migration**
```typescript
// We try new downgrade method, track which method was used
if (metadata.downgradeMethod === 'OLD_CANCEL_CREATE') {
  // Migrate to new method
} else if (metadata.downgradeMethod === 'UPDATE_API_SCHEDULED') {
  // Already on new method
}
```

**5. Compliance & Audit**
```typescript
// Legal requirement: Track all subscription changes
// Metadata provides immutable history of what happened and when
```

### Same Reasoning for Upgrade Flow

**`lastUpgradeAttempt`** and **`upgradeMethod: 'UPDATE_API'`**:
- Track when user upgraded
- Verify UPDATE API vs old method
- Calculate time-to-upgrade metrics
- Support: "I upgraded but didn't get charged correctly"
- Analytics: "Do users upgrade after trial or mid-cycle?"

### Metadata is Cheap, Insights are Valuable

- Storage cost: ~100 bytes per subscription
- Value: Priceless for debugging, analytics, compliance
- Best practice: Track more rather than less
