## Razorpay Subscription System Overview

### What Razorpay Provides

Razorpay's subscription system is built around **plans** and **subscriptions**:

```
Plan (Template)
├─ Billing Cycle (monthly, yearly, etc.)
├─ Price
├─ Total Count (number of billing cycles)
└─ Created once, reused for multiple customers

Subscription (Instance)
├─ Links: Customer + Plan
├─ Tracking: paid_count, remaining_count
├─ Lifecycle: authenticated → charged → completed
└─ One per customer per plan
```

### ⚠️ OUTDATED INFORMATION - See Correct Method Below

**Critical Update**: This section contains outdated information. Razorpay **DOES support plan changes** via the UPDATE API.

~~**Old Belief**: Razorpay subscriptions are immutable regarding plans.~~
- ✅ **CORRECTION**: You CAN change plan_id using `subscriptions.update()` API
- ✅ **CORRECTION**: Razorpay handles proration automatically
- ✅ **CORRECTION**: Same subscription ID is preserved
- ✅ **Official Method**: See Part 23 (Update Subscription) documentation

**What You Should Do**:
When user changes plans, use the **UPDATE API** (not subscription swap):
1. Call `razorpay.subscriptions.update(id, { plan_id, schedule_change_at })`
2. Razorpay calculates proration automatically
3. Razorpay charges the correct amount
4. Same subscription ID preserved
5. Listen for `subscription.updated` webhook

### ⚠️ DO NOT USE THIS APPROACH

**This section documents an outdated workaround that should NOT be used.**

### Step-by-Step Flow

```typescript
async function changePlan(
  userId: string,
  oldSubscriptionId: string,
  newPlanId: string
) {
  // Step 1: Get old subscription details
  const oldSub = await prisma.subscription.findUnique({
    where: { id: oldSubscriptionId },
    include: { plan: true }
  });
  
  const oldRazorpaySub = await razorpay.subscriptions.fetch(
    oldSub.razorpaySubscriptionId
  );
  
  // Step 2: Calculate proration credit
  const daysRemaining = differenceInDays(
    new Date(oldRazorpaySub.current_end * 1000),
    new Date()
  );
  const totalDays = getBillingCycleDays(oldSub.plan.billingCycle);
  const credit = Number(oldSub.plan.price) * (daysRemaining / totalDays);
  
  // Step 3: Cancel old Razorpay subscription
  await razorpay.subscriptions.cancel(
    oldSub.razorpaySubscriptionId,
    {
      cancel_at_cycle_end: false // Immediate cancellation
    }
  );
  
  // Step 4: Get new plan details
  const newPlan = await prisma.subscriptionPlan.findUnique({
    where: { id: newPlanId }
  });
  
  // Step 5: Calculate charge amount
  const chargeAmount = Number(newPlan.price) - credit;
  
  // Step 6: Create new Razorpay subscription with proration credit as negative addon
  // NOTE: Do NOT cancel old subscription yet! Cancel AFTER payment succeeds.
  
  // Step 7: Create new Razorpay subscription with proration addon
  const newRazorpaySub = await razorpay.subscriptions.create({
    plan_id: newPlan.razorpayPlanId,
    customer_id: oldRazorpaySub.customer_id,
    total_count: getCountForBillingCycle(newPlan.billingCycle),
    start_at: Math.floor(Date.now() / 1000), // Start immediately
    quantity: 1,
    
    // Apply proration credit as NEGATIVE addon (one-time discount)
    addons: [
      {
        item: {
          name: "Upgrade Proration Credit",
          amount: Math.round(credit * -100), // Negative amount in paise!
          currency: "INR",
          description: `Credit for ${daysRemaining} unused days on ${oldSub.plan.displayName}`
        }
      }
    ],
    
    notify: 1, // Send confirmation email
    notes: {
      userId,
      oldSubscriptionId: oldSub.razorpaySubscriptionId,
      replacingSubscription: 'true', // Mark for webhook detection
      prorationCredit: credit.toFixed(2),
      daysRemaining: daysRemaining.toString()
    }
  });
  
  // Step 8: Return checkout URL to user
  // User will be redirected to newRazorpaySub.short_url to complete payment
  // IMPORTANT: Old subscription is NOT canceled yet!
  // It will be canceled in the webhook AFTER payment succeeds (subscription.authenticated)
  
  return {
    checkoutUrl: newRazorpaySub.short_url,
    newSubscriptionId: newRazorpaySub.id,
    status: 'awaiting_payment'
  };
  
  // Step 9: In webhook (subscription.authenticated event):
  // - Cancel old Razorpay subscription
  // - Update database to new plan
  // This happens AFTER user successfully pays
  
  // Step 10: Update database (in webhook handler)
  await prisma.subscription.update({
    where: { id: oldSubscriptionId },
    data: {
      planId: newPlanId,
      razorpaySubscriptionId: newRazorpaySub.id,
      razorpayPlanId: newPlan.razorpayPlanId,
      currentPeriodStart: new Date(),
      currentPeriodEnd: addDays(new Date(), getBillingCycleDays(newPlan.billingCycle)),
      status: 'ACTIVE',
      updatedAt: new Date()
    }
  });
  
  // Step 9: Create history record
  await prisma.subscriptionHistory.create({
    data: {
      subscriptionId: oldSubscriptionId,
      action: chargeAmount > 0 ? 'UPGRADED' : 'DOWNGRADED',
      fromPlanId: oldSub.planId,
      toPlanId: newPlanId,
      reason: `Plan changed from ${oldSub.plan.displayName} to ${newPlan.displayName}`,
      metadata: {
        oldRazorpaySubId: oldSub.razorpaySubscriptionId,
        newRazorpaySubId: newRazorpaySub.id,
        prorationCredit: credit,
        chargeAmount: chargeAmount > 0 ? chargeAmount : 0,
        daysRemaining
      }
    }
  });
  
  return {
    newSubscriptionId: newRazorpaySub.id,
    credit,
    chargeAmount: chargeAmount > 0 ? chargeAmount : 0
  };
}
```

### Why This Works

✅ **Razorpay tracks new subscription independently**
✅ **Old subscription cleanly closed (paid_count preserved)**
✅ **New subscription starts fresh with correct billing**
✅ **Webhook events fire for new subscription lifecycle**
✅ **Customer sees clean billing history**

## Proration: Razorpay Handles It Automatically

### ⚠️ CORRECTION: Razorpay DOES Calculate Proration

**Updated Understanding** (Based on Official Documentation): 
- ✅ Razorpay **HAS built-in proration logic** (when using UPDATE API)
- ✅ Razorpay **DOES calculate credits automatically** (with `schedule_change_at: 'now'`)
- ✅ Razorpay charges the correct prorated amount
- ⚠️ You only need manual calculation for PREVIEW purposes (showing user what to expect)

**Official Razorpay Method**:
```javascript
// ✅ Razorpay handles proration automatically
await razorpay.subscriptions.update(subscriptionId, {
  plan_id: newPlanId,
  schedule_change_at: 'now', // Razorpay calculates proration
  customer_notify: true
});

// Razorpay automatically:
// 1. Calculates unused time on old plan
// 2. Calculates new plan cost for remaining period
// 3. Charges the difference
// 4. Updates the subscription
```

**When YOU Need to Calculate**:
- ✅ For PREVIEW only (showing user expected charge before they confirm)
- ✅ For displaying proration breakdown in UI
- ✅ For validation/verification purposes
- ❌ NOT for actual charging (Razorpay does that)

### Proration Calculation Library

```typescript
// lib/proration-calculator.ts

import { BillingCycle } from '@/generated/prisma';
import { differenceInDays, differenceInHours } from 'date-fns';

/**
 * Get total days in a billing cycle
 */
function getBillingCycleDays(cycle: BillingCycle): number {
  switch (cycle) {
    case 'MONTHLY':
      return 30;
    case 'HALFYEARLY':
      return 180;
    case 'YEARLY':
      return 365;
    default:
      throw new Error(`Unknown billing cycle: ${cycle}`);
  }
}

/**
 * Calculate prorated credit for unused time
 * 
 * @param planPrice - Original plan price (in rupees)
 * @param billingCycle - MONTHLY, HALFYEARLY, or YEARLY
 * @param currentPeriodEnd - End of current billing period
 * @returns Credit amount in rupees (2 decimal places)
 */
export function calculateProrationCredit(
  planPrice: number,
  billingCycle: BillingCycle,
  currentPeriodEnd: Date
): number {
  const now = new Date();
  
  // If period already ended, no credit
  if (currentPeriodEnd <= now) {
    return 0;
  }
  
  // Calculate days remaining
  const daysRemaining = differenceInDays(currentPeriodEnd, now);
  
  // Include partial day (hours)
  const hoursRemaining = differenceInHours(currentPeriodEnd, now);
  const fractionalDays = hoursRemaining / 24;
  
  // Total days in cycle
  const totalDays = getBillingCycleDays(billingCycle);
  
  // Calculate credit
  const credit = planPrice * (fractionalDays / totalDays);
  
  // Round to 2 decimal places
  return Math.round(credit * 100) / 100;
}

/**
 * Calculate charge amount for plan change
 * 
 * @param oldPlan - Current plan details
 * @param newPlan - New plan details
 * @param currentPeriodEnd - End of current billing period
 * @returns Object with credit and charge amount
 */
export function calculatePlanChangeCharge(
  oldPlan: {
    price: number;
    billingCycle: BillingCycle;
  },
  newPlan: {
    price: number;
    billingCycle: BillingCycle;
  },
  currentPeriodEnd: Date
): {
  credit: number;
  chargeAmount: number;
  isUpgrade: boolean;
  isDowngrade: boolean;
  daysRemaining: number;
} {
  // Calculate credit from old plan
  const credit = calculateProrationCredit(
    oldPlan.price,
    oldPlan.billingCycle,
    currentPeriodEnd
  );
  
  // New plan full price
  const newPlanPrice = newPlan.price;
  
  // Charge = new price - credit
  const chargeAmount = Math.max(0, newPlanPrice - credit);
  
  // Determine if upgrade or downgrade
  const isUpgrade = newPlanPrice > oldPlan.price;
  const isDowngrade = newPlanPrice < oldPlan.price;
  
  // Days remaining
  const daysRemaining = Math.max(0, differenceInDays(currentPeriodEnd, new Date()));
  
  return {
    credit: Math.round(credit * 100) / 100,
    chargeAmount: Math.round(chargeAmount * 100) / 100,
    isUpgrade,
    isDowngrade,
    daysRemaining
  };
}

/**
 * Calculate credit to apply for downgrade (no refund policy)
 * 
 * @param oldPlan - Current plan details
 * @param newPlan - New plan details (lower price)
 * @param currentPeriodEnd - End of current billing period
 * @returns Credit to add to user account
 */
export function calculateDowngradeCredit(
  oldPlan: {
    price: number;
    billingCycle: BillingCycle;
  },
  newPlan: {
    price: number;
    billingCycle: BillingCycle;
  },
  currentPeriodEnd: Date
): {
  credit: number;
  monthsCovered: number;
  daysRemaining: number;
} {
  // Get unused value from old plan
  const unusedValue = calculateProrationCredit(
    oldPlan.price,
    oldPlan.billingCycle,
    currentPeriodEnd
  );
  
  // Calculate how many months of new plan this covers
  const monthsCovered = unusedValue / newPlan.price;
  
  const daysRemaining = Math.max(0, differenceInDays(currentPeriodEnd, new Date()));
  
  return {
    credit: Math.round(unusedValue * 100) / 100,
    monthsCovered: Math.round(monthsCovered * 10) / 10, // 1 decimal
    daysRemaining
  };
}

/**
 * Get human-readable proration explanation
 */
export function getProrationExplanation(
  oldPlan: { price: number; billingCycle: BillingCycle; displayName: string },
  newPlan: { price: number; billingCycle: BillingCycle; displayName: string },
  currentPeriodEnd: Date
): string {
  const calc = calculatePlanChangeCharge(oldPlan, newPlan, currentPeriodEnd);
  
  if (calc.isUpgrade) {
    return `
You'll be charged ₹${calc.chargeAmount.toFixed(2)} today:
• ${newPlan.displayName}: ₹${newPlan.price}
• Credit for ${calc.daysRemaining} days unused on ${oldPlan.displayName}: -₹${calc.credit.toFixed(2)}
• Total: ₹${calc.chargeAmount.toFixed(2)}

Your new subscription starts immediately and lasts ${getBillingCycleDays(newPlan.billingCycle)} days.
    `.trim();
  }
  
  if (calc.isDowngrade) {
    const downgradeCalc = calculateDowngradeCredit(oldPlan, newPlan, currentPeriodEnd);
    return `
You have ${calc.daysRemaining} days remaining on ${oldPlan.displayName}.

Option 1 (Recommended): Schedule Downgrade
• Keep ${oldPlan.displayName} features until ${currentPeriodEnd.toLocaleDateString()}
• Switch to ${newPlan.displayName} at renewal
• No charge today

Option 2: Immediate Downgrade with Credit
• Unused value: ₹${downgradeCalc.credit.toFixed(2)}
• Applied as account credit
• Covers ${downgradeCalc.monthsCovered.toFixed(1)} months of ${newPlan.displayName}
• Next charge: After credit exhausted
    `.trim();
  }
  
  return `No charge difference detected.`;
}
```

## Addon Charges for Immediate Upgrades

### What Are Addons?

**Addons** = One-time charges added to a subscription's next billing.

**Use Case**: 
When upgrading, you can add the prorated charge as an addon to the new subscription's first bill.

### Addon API

```javascript
const subscription = await razorpay.subscriptions.create({
  plan_id: 'plan_HalfYearly',
  customer_id: 'cust_123',
  total_count: 6,
  start_at: Math.floor(Date.now() / 1000),
  addons: [
    {
      item: {
        name: 'Upgrade Charge (Prorated)',
        amount: 1566667, // ₹15,666.67 in paise
        currency: 'INR',
        description: 'Credit: ₹2,333.33 for 20 days unused on Monthly plan'
      }
    }
  ]
});
```

**Result**:
- First charge: ₹18,000 (plan) + ₹15,666.67 (addon) = ₹33,666.67
- Wait... that's WRONG! ❌

**Problem**: Addons are ADDED to plan price, not REPLACING it.

### ❌ INCORRECT Approach 1: Separate Order + Subscription

**⚠️ Common Mistake**: Using separate one-time order, then creating subscription.

```javascript
// ❌ WRONG - DO NOT DO THIS
// Step 1: Create order for proration
const order = await razorpay.orders.create({
  amount: 1566667, // ₹15,666.67
  currency: 'INR'
});
// User pays ₹15,666.67 here

// Step 2: After payment, create subscription
const newSub = await razorpay.subscriptions.create({
  plan_id: 'plan_HalfYearly', // ₹18,000
  start_at: Math.floor(Date.now() / 1000)
});
// ❌ User redirected AGAIN to pay ₹18,000!
```

**Why This Is Wrong**:
- User pays ₹15,666.67 for the order ✅
- Then Razorpay asks user to pay **ANOTHER ₹18,000** for subscription authentication ❌
- **Total paid: ₹15,666.67 + ₹18,000 = ₹33,666.67** (DOUBLE CHARGE!) ❌
- User expected to pay only ₹15,666.67 today!

**The Problem**: 
- Razorpay subscriptions **ALWAYS require authentication**
- Authentication = First payment + auto-pay authorization
- You **CANNOT** skip the first payment

### ✅ CORRECT Approach: Use UPDATE Subscription API (Official Method)

**⚠️ UPDATE (Based on Official Razorpay Documentation):**

Razorpay has an official **UPDATE Subscription API** that handles plan changes with **automatic proration**. This is the recommended, officially supported method.

**The Official Solution: Use subscriptions.update()**

```javascript
// ✅ OFFICIAL METHOD - Documented in Razorpay API
// User upgrading: Monthly (20 days left) → Half-Yearly (₹18,000)

// Simply update the existing subscription
await razorpay.subscriptions.update(subscriptionId, {
  plan_id: 'plan_HalfYearly', // New plan ID
  schedule_change_at: 'now', // Apply immediately (with proration)
  customer_notify: true // Razorpay sends notification email
});

// That's it! Razorpay handles:
// 1. Proration calculation automatically
// 2. Charging the correct amount
// 3. Keeping same subscription ID
// 4. Firing subscription.updated webhook
```

**What Happens (Officially)**:
1. **Razorpay Calculates Proration**:
   - Detects unused time on old plan (20 days)
   - Calculates credit value: ₹2,333.33
   - Determines correct charge: ₹18,000 - ₹2,333.33 = ₹15,666.67

2. **Automatic Charge**:
   - Razorpay charges ₹15,666.67 to saved payment method
   - No checkout page needed (uses existing authorization)
   - User sees charge on their statement

3. **Subscription Updated**:
   - Same subscription ID (e.g., `sub_00000000000001`)
   - Plan changes immediately to Half-Yearly
   - Status: Stays `active`
   - Webhook fires: `subscription.updated`

4. **Next Charge (Day 180)**:
   - Razorpay auto-charges: ₹18,000 (full price)
   - Uses existing auto-pay authorization

**Result**:
- ✅ **Official Razorpay API** (documented and supported)
- ✅ **Automatic proration** (Razorpay calculates, not you)
- ✅ **Same subscription ID** (no dual subscriptions)
- ✅ **No checkout needed** (seamless upgrade)
- ✅ **Simple webhook** (`subscription.updated`, not `.authenticated`)
- ✅ **70% less code** than create-new approach
- ✅ **No manual cancellation** of old subscription
- ✅ **Continuous payment history**

**When to Use**:
- ✅ Plan upgrades (MINI → MAXI)
- ✅ Plan downgrades (MAXI → MIDI)
- ✅ Immediate or scheduled changes
- ✅ Quantity changes (add/remove seats)

**Limitations**:
- ❌ Cannot update UPI/Emandate subscriptions (must cancel + create new)
- ❌ Only works on `authenticated` or `active` subscriptions

### Understanding Razorpay UPDATE vs CREATE

**Critical Difference**: When to update vs when to create new subscription.

**UPDATE API (Recommended for Plan Changes)**:

```javascript
// ✅ Use UPDATE for plan changes (upgrades/downgrades)
await razorpay.subscriptions.update(subscriptionId, {
  plan_id: 'plan_newPlan',
  schedule_change_at: 'now', // or 'cycle_end'
  customer_notify: true
});
```

**Advantages**:
- ✅ Same subscription ID preserved
- ✅ Razorpay handles proration automatically
- ✅ No checkout page needed (uses saved payment method)
- ✅ Clean payment history continuity
- ✅ Simple webhook: `subscription.updated`

**CREATE API (When UPDATE Won't Work)**:

```javascript
// Use CREATE only when UPDATE is not possible
const newSub = await razorpay.subscriptions.create({
  plan_id: 'plan_newPlan',
  customer_id: customerId,
  total_count: 6,
  start_at: Math.floor(Date.now() / 1000)
});
```

**When to Use CREATE**:
- ❌ UPI/Emandate subscriptions (cannot be updated)
- ❌ Expired subscriptions (must create fresh)
- ❌ Cancelled subscriptions (if too old)
- ❌ Creating first subscription for a new customer

**Timeline Comparison**:

**UPDATE API Flow:**
```
User clicks upgrade
  ↓
Call subscriptions.update()
  ↓
Razorpay charges saved payment method automatically
  ↓
subscription.updated webhook fires
  ↓
Update database with new plan
  ↓
Done! Same subscription ID
```

**CREATE API Flow (Old Method):**
```
User clicks upgrade
  ↓
Create NEW subscription (new ID)
  ↓
Redirect to checkout page (new auth required)
  ↓
User pays & authorizes
  ↓
subscription.authenticated webhook fires
  ↓
Cancel OLD subscription manually
  ↓
Update database with NEW subscription ID
  ↓
Done! But with new subscription ID
```

**Key Insights**:
- ✅ **UPDATE is simpler** (no checkout, no new ID)
- ✅ **UPDATE is seamless** (automatic charge, no user action)
- ✅ **UPDATE is reliable** (Razorpay-calculated proration)
- ✅ **UPDATE is official** (documented and supported)
- ⚠️ **CREATE is backup** (only when UPDATE impossible)

## Limitations & Workarounds

### Limitation 1: Scheduled Changes Have No Webhook

**Problem**: When Razorpay applies a scheduled change, no webhook fires.

**Workaround**: Cron job to poll subscriptions with `has_scheduled_changes: true`.

**Code**:
```typescript
// Cron job: Check scheduled changes daily
async function checkScheduledChanges() {
  const subscriptions = await prisma.subscription.findMany({
    where: {
      status: 'ACTIVE',
      // Filter subscriptions we think have scheduled changes
      metadata: {
        path: ['hasScheduledChange'],
        equals: true
      }
    }
  });
  
  for (const sub of subscriptions) {
    // Fetch from Razorpay
    const razorpaySub = await razorpay.subscriptions.fetch(
      sub.razorpaySubscriptionId
    );
    
    // Check if change was applied
    if (!razorpaySub.has_scheduled_changes && razorpaySub.plan_id !== sub.razorpayPlanId) {
      // Change was applied!
      console.log(`✅ Scheduled change applied for ${sub.id}`);
      
      // Update database
      const newPlan = await prisma.subscriptionPlan.findUnique({
        where: { razorpayPlanId: razorpaySub.plan_id }
      });
      
      await prisma.subscription.update({
        where: { id: sub.id },
        data: {
          planId: newPlan!.id,
          razorpayPlanId: razorpaySub.plan_id,
          metadata: {
            hasScheduledChange: false
          },
          updatedAt: new Date()
        }
      });
      
      // Create history
      await prisma.subscriptionHistory.create({
        data: {
          subscriptionId: sub.id,
          action: 'DOWNGRADED',
          toPlanId: newPlan!.id,
          reason: 'Scheduled plan change applied by Razorpay',
          metadata: {
            appliedAt: new Date(),
            detectedVia: 'cron_polling'
          }
        }
      });
    }
  }
}
```

### Example 1: Immediate Upgrade (Monthly → Half-Yearly)

**Scenario**:
- Current: Monthly (₹3,500/mo), 20 days remaining, credit = ₹2,333.33
- New: Half-Yearly (₹18,000/6mo = 180 days)
- User wants immediate upgrade

**Payment Timeline**:
```
Day 0 (Today):
├─ User pays ₹15,666.67 (₹18,000 - ₹2,333.33 credit)
├─ One-time payment via Razorpay Order
└─ Gets immediate access to Half-Yearly features

Day 180 (6 months later):
├─ Razorpay auto-charges ₹18,000 (recurring)
├─ subscription.charged webhook fires
└─ Subscription continues for another 180 days

Total: User pays ₹15,666.67 + ₹18,000 = ₹33,666.67 for ~200 days
This is correct proration! ✅
```

**Full Implementation**:

```typescript
// src/app/api/subscription/upgrade/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';
import { calculatePlanChangeCharge } from '@/lib/proration-calculator';
import { differenceInDays, addDays } from 'date-fns';

export async function POST(req: Request) {
  try {
    const { userId: clerkId } = await auth();
    if (!clerkId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const { newPlanId } = await req.json();
    
    // Get user and current subscription
    const user = await prisma.user.findUnique({
      where: { id: clerkId },
      include: {
        subscription: {
          include: { plan: true }
        }
      }
    });
    
    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No active subscription' },
        { status: 400 }
      );
    }
    
    const currentSub = user.subscription;
    
    // Get new plan details
    const newPlan = await prisma.subscriptionPlan.findUnique({
      where: { id: newPlanId }
    });
    
    if (!newPlan) {
      return NextResponse.json({ error: 'Plan not found' }, { status: 404 });
    }
    
    // Calculate proration
    const calc = calculatePlanChangeCharge(
      {
        price: Number(currentSub.plan.price),
        billingCycle: currentSub.plan.billingCycle
      },
      {
        price: Number(newPlan.price),
        billingCycle: newPlan.billingCycle
      },
      currentSub.currentPeriodEnd
    );
    
    if (!calc.isUpgrade) {
      return NextResponse.json(
        { error: 'New plan is not an upgrade' },
        { status: 400 }
      );
    }
    
    // ❌ DO NOT CANCEL OLD SUBSCRIPTION HERE!
    
    // Create new Razorpay subscription with negative addon for credit
    const newRazorpaySub = await razorpay.subscriptions.create({
      plan_id: newPlan.razorpayPlanId!,
      customer_id: currentSub.razorpayCustomerId!,
      total_count: Math.ceil(
        getBillingCycleDays(newPlan.billingCycle) / 30
      ),
      start_at: Math.floor(Date.now() / 1000),
      
      // Apply proration credit as NEGATIVE addon (one-time discount)
      addons: [
        {
          item: {
            name: 'Upgrade Proration Credit',
            amount: Math.round(calc.credit * -100), // NEGATIVE amount in paise
            currency: 'INR',
            description: `Credit for ${calc.daysRemaining} days unused on ${currentSub.plan.displayName}`
          }
        }
      ],
      
      notify: 1,
      notes: {
        userId: clerkId,
        oldSubscriptionId: currentSub.razorpaySubscriptionId,
        replacedSubscriptionId: currentSub.razorpaySubscriptionId,
        upgradeType: 'immediate_with_proration',
        credit: calc.credit.toFixed(2),
        daysRemaining: calc.daysRemaining.toString()
      }
    });
    
    // Return subscription details to frontend
    return NextResponse.json({
      subscriptionId: newRazorpaySub.id,
      checkoutUrl: newRazorpaySub.short_url, // Redirect user here
      amount: calc.chargeAmount, // Amount user will pay (after credit)
      currency: 'INR',
      proration: {
        planPrice: Number(newPlan.price),
        credit: calc.credit,
        chargeAmount: calc.chargeAmount,
        daysRemaining: calc.daysRemaining
      },
      newPlan: {
        id: newPlan.id,
        name: newPlan.displayName,
        price: Number(newPlan.price),
        billingCycle: newPlan.billingCycle
      }
    });
    
  } catch (error) {
    console.error('❌ Upgrade error:', error);
    return NextResponse.json(
      { error: 'Failed to process upgrade' },
      { status: 500 }
    );
  }
}
```

**Handle Subscription Authentication via Webhook**:

```typescript
// src/app/api/webhooks/razorpay/route.ts

import { NextResponse } from 'next/server';
import crypto from 'crypto';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';
import { addDays } from 'date-fns';

function getBillingCycleDays(cycle: string): number {
  switch (cycle) {
    case 'MONTHLY': return 30;
    case 'HALFYEARLY': return 180;
    case 'YEARLY': return 365;
    default: return 30;
  }
}

export async function POST(req: Request) {
  try {
    const body = await req.text();
    const signature = req.headers.get('x-razorpay-signature');
    
    // Verify webhook signature
    const secret = process.env.RAZORPAY_WEBHOOK_SECRET!;
    const expectedSignature = crypto
      .createHmac('sha256', secret)
      .update(body)
      .digest('hex');
    
    if (expectedSignature !== signature) {
      return NextResponse.json({ error: 'Invalid signature' }, { status: 400 });
    }
    
    const event = JSON.parse(body);
    
    // Handle subscription.authenticated event
    if (event.event === 'subscription.authenticated') {
      const subscription = event.payload.subscription.entity;
      const payment = event.payload.payment.entity;
      
      // Check if this is an upgrade (check notes)
      if (subscription.notes?.upgradeType === 'immediate_with_proration') {
        const userId = subscription.notes.userId;
        const replacedSubscriptionId = subscription.notes.replacedSubscriptionId;
        const credit = parseFloat(subscription.notes.credit || '0');
        const oldSubscriptionId = subscription.notes.oldSubscriptionId;

        // ✅ NOW cancel old subscription (payment succeeded!)
        if (oldSubscriptionId) {
          await razorpay.subscriptions.cancel(
            oldSubscriptionId,
            { cancel_at_cycle_end: false }
          );
          console.log(`✅ Old subscription ${oldSubscriptionId} canceled after payment`);
        }
        
        // Get user's subscription record
        const userSub = await prisma.subscription.findFirst({
          where: {
            userId,
            razorpaySubscriptionId: replacedSubscriptionId
          },
          include: { plan: true }
        });
        
        if (!userSub) {
          console.error('❌ Subscription not found for upgrade');
          return NextResponse.json({ error: 'Subscription not found' }, { status: 404 });
        }
        
        // Get new plan
        const newPlan = await prisma.subscriptionPlan.findUnique({
          where: { razorpayPlanId: subscription.plan_id }
        });
        
        if (!newPlan) {
          console.error('❌ New plan not found');
          return NextResponse.json({ error: 'Plan not found' }, { status: 404 });
        }
        
        // Calculate period dates
        const billingCycleDays = getBillingCycleDays(newPlan.billingCycle);
        const newPeriodStart = new Date(subscription.current_start * 1000);
        const newPeriodEnd = new Date(subscription.current_end * 1000);
        
        // Update database
        await prisma.$transaction(async (tx) => {
          // Update subscription
          await tx.subscription.update({
            where: { id: userSub.id },
            data: {
              planId: newPlan.id,
              razorpaySubscriptionId: subscription.id,
              razorpayPlanId: subscription.plan_id,
              billingCycle: newPlan.billingCycle,
              currentPeriodStart: newPeriodStart,
              currentPeriodEnd: newPeriodEnd,
              status: 'ACTIVE',
              updatedAt: new Date()
            }
          });
          
          // Create payment record
          await tx.payment.create({
            data: {
              userId,
              subscriptionId: userSub.id,
              razorpayPaymentId: payment.id,
              razorpaySubscriptionId: subscription.id,
              amountPaid: payment.amount / 100,
              subtotal: payment.amount / 100,
              currency: payment.currency.toUpperCase(),
              status: 'SUCCESS',
              paymentMethod: payment.method,
              description: `Upgrade: ${userSub.plan.displayName} → ${newPlan.displayName}`,
              metadata: {
                type: 'upgrade_with_proration',
                credit: credit.toFixed(2),
                planPrice: Number(newPlan.price),
                nextRecurringCharge: newPeriodEnd.toISOString(),
                nextChargeAmount: Number(newPlan.price)
              },
              paidAt: new Date(payment.created_at * 1000)
            }
          });
          
          // Create history
          await tx.subscriptionHistory.create({
            data: {
              subscriptionId: userSub.id,
              action: 'UPGRADED',
              fromPlanId: userSub.planId,
              toPlanId: newPlan.id,
              fromStatus: userSub.status,
              toStatus: 'ACTIVE',
              reason: `Upgraded from ${userSub.plan.displayName} to ${newPlan.displayName}`,
              metadata: {
                oldRazorpaySubId: replacedSubscriptionId,
                newRazorpaySubId: subscription.id,
                paymentId: payment.id,
                prorationCharge: payment.amount / 100,
                credit: credit.toFixed(2),
                newPeriodStart: newPeriodStart.toISOString(),
                newPeriodEnd: newPeriodEnd.toISOString(),
                upgradedAt: new Date().toISOString()
              }
            }
          });
        });
        
        console.log(`✅ Upgrade completed for user ${userId}`);
      }
    }
    
    return NextResponse.json({ received: true });
    
  } catch (error) {
    console.error('❌ Webhook error:', error);
    return NextResponse.json({ error: 'Webhook processing failed' }, { status: 500 });
  }
}
```

```typescript
// src/app/api/subscription/schedule-downgrade/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';
import { differenceInDays } from 'date-fns';

export async function POST(req: Request) {
  try {
    const { userId: clerkId } = await auth();
    if (!clerkId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const { newPlanId } = await req.json();
    
    // Get user and current subscription
    const user = await prisma.user.findUnique({
      where: { id: clerkId },
      include: {
        subscription: {
          include: { plan: true }
        }
      }
    });
    
    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No active subscription' },
        { status: 400 }
      );
    }
    
    const currentSub = user.subscription;
    
    // Get new plan
    const newPlan = await prisma.subscriptionPlan.findUnique({
      where: { id: newPlanId }
    });
    
    if (!newPlan) {
      return NextResponse.json({ error: 'Plan not found' }, { status: 404 });
    }
    
    // Check if downgrade
    if (Number(newPlan.price) >= Number(currentSub.plan.price)) {
      return NextResponse.json(
        { error: 'New plan is not a downgrade' },
        { status: 400 }
      );
    }
    
    // Check usage eligibility
    const usageCheck = await checkDowngradeEligibility(clerkId, newPlanId);
    if (!usageCheck.canDowngrade) {
      return NextResponse.json(
        {
          error: 'Usage exceeds new plan limits',
          overages: usageCheck.overages
        },
        { status: 400 }
      );
    }
    
    // Schedule change in Razorpay
    const scheduleAt = Math.floor(currentSub.currentPeriodEnd.getTime() / 1000);
    
    await razorpay.subscriptions.update(
      currentSub.razorpaySubscriptionId!,
      {
        schedule_change: {
          plan_id: newPlan.razorpayPlanId!,
          schedule_at: scheduleAt
        },
        customer_notify: 1
      }
    );
    
    // Update database
    await prisma.$transaction(async (tx) => {
      // Store scheduled change in subscription metadata
      await tx.subscription.update({
        where: { id: currentSub.id },
        data: {
          metadata: {
            scheduledChange: {
              type: 'DOWNGRADE',
              newPlanId,
              newPlanName: newPlan.displayName,
              effectiveDate: currentSub.currentPeriodEnd,
              scheduledAt: new Date()
            },
            hasScheduledChange: true
          }
        }
      });
      
      // Create subscription history
      await tx.subscriptionHistory.create({
        data: {
          subscriptionId: currentSub.id,
          action: 'DOWNGRADED',
          fromPlanId: currentSub.planId,
          toPlanId: newPlanId,
          fromStatus: currentSub.status,
          toStatus: currentSub.status, // No immediate status change
          reason: `Scheduled downgrade from ${currentSub.plan.displayName} to ${newPlan.displayName}`,
          metadata: {
            effectiveDate: currentSub.currentPeriodEnd,
            daysUntilChange: differenceInDays(
              currentSub.currentPeriodEnd,
              new Date()
            ),
            scheduledInRazorpay: true
          }
        }
      });
    });
    
    return NextResponse.json({
      success: true,
      message: 'Downgrade scheduled successfully',
      effectiveDate: currentSub.currentPeriodEnd,
      daysUntilChange: differenceInDays(
        currentSub.currentPeriodEnd,
        new Date()
      ),
      currentPlan: currentSub.plan.displayName,
      newPlan: newPlan.displayName
    });
    
  } catch (error) {
    console.error('❌ Schedule downgrade error:', error);
    return NextResponse.json(
      { error: 'Failed to schedule downgrade' },
      { status: 500 }
    );
  }
}

// Helper function to check usage
async function checkDowngradeEligibility(
  userId: string,
  newPlanId: string
): Promise<{ canDowngrade: boolean; overages: any[] }> {
  // Get current usage
  const usage = await prisma.usageRecord.findMany({
    where: {
      userId,
      periodEnd: { gte: new Date() }
    }
  });
  
  const currentUsage = {
    products: usage.find(u => u.metricType === 'PRODUCTS')?.count || 0,
    orders: usage.find(u => u.metricType === 'ORDERS')?.count || 0,
    storageGB: usage.find(u => u.metricType === 'STORAGE_GB')?.count || 0
  };
  
  // Get new plan limits
  const newPlan = await prisma.subscriptionPlan.findUnique({
    where: { id: newPlanId }
  });
  
  const overages = [];
  
  if (currentUsage.products > (newPlan!.maxProducts || Infinity)) {
    overages.push({
      metric: 'Products',
      current: currentUsage.products,
      limit: newPlan!.maxProducts,
      excess: currentUsage.products - newPlan!.maxProducts!
    });
  }
  
  if (currentUsage.orders > (newPlan!.maxOrders || Infinity)) {
    overages.push({
      metric: 'Orders',
      current: currentUsage.orders,
      limit: newPlan!.maxOrders,
      excess: currentUsage.orders - newPlan!.maxOrders!
    });
  }
  
  if (currentUsage.storageGB > (newPlan!.maxStorageGB || Infinity)) {
    overages.push({
      metric: 'Storage',
      current: currentUsage.storageGB,
      limit: newPlan!.maxStorageGB,
      excess: currentUsage.storageGB - newPlan!.maxStorageGB!
    });
  }
  
  return {
    canDowngrade: overages.length === 0,
    overages
  };
}
```

## Summary: Key Razorpay Insights

### ✅ What Razorpay Provides

1. **Subscription Lifecycle Management**
   - Create, cancel, pause, resume
   - Webhook events for all lifecycle changes
   - Scheduled changes API

2. **Flexible Billing**
   - Multiple billing cycles
   - Per-seat/per-unit pricing
   - Addon charges

3. **Customer Management**
   - Customer profiles
   - Multiple subscriptions per customer
   - Email notifications

### ❌ What Razorpay Doesn't Provide

1. **Proration Logic**
   - You must calculate unused value
   - No built-in credit system
   - Manual charge difference calculation

2. **Direct Plan Changes**
   - Cannot update `plan_id` of running subscription
   - Must use subscription swap strategy
   - Scheduled changes only work for future dates

3. **Webhook for Scheduled Changes**
   - No notification when scheduled change applied
   - Must poll via cron job
   - Manual database sync required

### 🎯 Recommended Strategy

**For Your SaaS (ShopPulseAdmin)**:

1. **Upgrades** (ACTIVE → Higher Tier):
   ```
   ✅ Immediate effect
   ✅ Prorated charge (you calculate)
   ✅ Subscription swap (cancel old + create new)
   ✅ User pays difference today
   ```

2. **Downgrades** (Higher → Lower Tier):
   ```
   ✅ Scheduled at period end (simplest)
   ✅ Use Razorpay schedule_change API
   ✅ No refund, user keeps features until renewal
   ✅ Cron job to detect when change applied
   ```

3. **Reactivation** (CANCELED → ACTIVE):
   ```
   ✅ Update status in your DB
   ✅ Re-enable auto_renew on Razorpay subscription
   ✅ No charge until next period
   ✅ Restore user access immediately
   ```
