## 🛡️ PICKUP_FAILED Detection

### Problem
> "Redis crash won't change PICKUP_QUEUED to PICKUP_FAILED automatically"

### Solution: Health Check Cron (every 30 mins)

| Scenario | Who Detects | Action |
|----------|-------------|--------|
| Shiprocket API error | Pickup Cron | Sets FAILED + reason |
| Redis crash (order lost) | Health Check Cron | Finds stale → Sets FAILED |
| Rate limit (429) | Pickup Cron | Stays in queue for retry |

```typescript
// Health Check Cron: /api/cron/pickup-health-check
// Runs every 30 minutes

const staleOrders = await db.shipment.findMany({
  where: {
    status: 'PICKUP_QUEUED',
    queuedAt: { lt: new Date(Date.now() - 4 * 60 * 60 * 1000) } // >4 hours
  }
});

for (const order of staleOrders) {
  const existsInRedis = await redis.sismember(`pickup:${order.storeId}:*`, order.shiprocketId);
  if (!existsInRedis) {
    await db.shipment.update({
      where: { id: order.id },
      data: {
        status: 'PICKUP_FAILED',
        failureReason: 'Lost from queue (Redis/server issue)',
        failedAt: new Date()
      }
    });
  }
}
```

## 📊 Database Schema Updates

```prisma
model Shipment {
  // ... existing fields
  
  status         ShipmentStatus @default(PENDING)
  queuedAt       DateTime?      // When added to pickup queue
  scheduledAt    DateTime?      // When scheduled with Shiprocket
  failedAt       DateTime?      // When scheduling failed
  failureReason  String?        // Why it failed
  retryCount     Int            @default(0)
}

enum ShipmentStatus {
  PENDING
  AWB_ASSIGNED
  LABEL_GENERATED
  PICKUP_QUEUED      // In Redis queue
  PICKUP_SCHEDULED   // Scheduled with courier
  PICKUP_FAILED      // Failed (needs retry)
  PICKED_UP
  IN_TRANSIT
  OUT_FOR_DELIVERY
  DELIVERED
  RTO_INITIATED
  RTO_IN_TRANSIT
  RTO_DELIVERED
  CANCELLED
}
```

### ✅ Feature 5: Retry Mechanism
> Auto-retry transient failures, manual retry for persistent

```typescript
async function processWithRetry(queueKey: string): Promise<void> {
  const shipmentIds = await redis.smembers(queueKey);
  
  try {
    await shiprocket.schedulePickup(shipmentIds);
    await db.shipment.updateMany({
      where: { shiprocketId: { in: shipmentIds } },
      data: { status: 'PICKUP_SCHEDULED' }
    });
    await redis.del(queueKey); // Clear on success
  } catch (error) {
    // DON'T delete - will retry next cron
    await db.shipment.updateMany({
      where: { shiprocketId: { in: shipmentIds } },
      data: { status: 'PICKUP_FAILED', failureReason: error.message }
    });
  }
}
```
