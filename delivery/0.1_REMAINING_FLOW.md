## 📋 Quick Reference

### Flow Types
| Flow | Description | Uses Pickup Queue? |
|------|-------------|:------------------:|
| **Batch Ship** | Select multiple orders → Ship together | ✅ |
| **One-Click Ship** | Quick ship from order details | ✅ |
| **Auto-Ship** | Automatic after payment | ✅ |
| **Manual Ship** | Seller enters own AWB | ❌ |

> **Manual Ship ≠ Shiprocket!** Manual = seller uses own courier (Speed Post, local delivery)

## 🔗 End-to-End Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  SETUP (One-time)                                                           │
│  1. Connect Shiprocket → Settings → Integrations                           │
│  2. Add Pickup Locations                                                    │
│  3. Configure Package Presets                                               │
│  4. Set Pickup Frequency (2hr/3hr/4hr/6hr/daily)                           │
├─────────────────────────────────────────────────────────────────────────────┤
│  SHIPPING FLOW                                                              │
│                                                                             │
│  Order Created → [Batch Ship / One-Click Ship / Auto-Ship]                 │
│       ↓                                                                     │
│  Create Shipment → AWB Assigned → Label Generated                          │
│       ↓                                                                     │
│  Handover Method?                                                           │
│    ├─ PICKUP → addToPickupQueue() → Redis Queue                            │
│    └─ DROPOFF → Done (hub scan triggers webhook)                           │
│       ↓                                                                     │
│  Cron Processes Queue → Schedule Pickup → Create PickupBatch               │
│       ↓                                                                     │
│  Manifest Generated → Courier Picks Up → Webhook Updates Status            │
├─────────────────────────────────────────────────────────────────────────────┤
│  SELLER'S MANUAL TASKS                                                      │
│  1. Download labels from Shipments page (or Pickups page)                  │
│  2. Print labels                                                            │
│  3. Match to boxes by Order ID, stick                                       │
│  4. Download manifest from Pickups page                                     │
│  5. Hand packages + manifest to courier                                     │
└─────────────────────────────────────────────────────────────────────────────┘
```
