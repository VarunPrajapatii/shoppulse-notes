## Reactivation Scenarios Overview

### What is Reactivation?

**Reactivation** = User previously canceled subscription, now wants it back

**Statuses that can reactivate**:
- `CANCELED` - User canceled but period hasn't ended yet (can keep same plan or upgrade)
- `EXPIRED` - Subscription already ended (must create new subscription)

**Statuses that CANNOT reactivate**:
- `PAST_DUE` - Payment failed (fix payment, don't reactivate)
- `COMPLETING` - Special status, handle separately

---

### Reactivation Types

| Type | Description | Credit Handling |
|------|-------------|-----------------|
| **Same Plan** | Cancel cancellation, resume current plan | No credit (already paid) |
| **Upgrade** | Cancel + switch to higher plan | Calculate proration from remaining days |
| **Downgrade** | Not recommended (user already canceling) | Block or schedule for next period |
| **New Plan** | After EXPIRED, create fresh subscription | No credit (clean slate) |

---

### Common User Stories

**Story 1**: "I canceled but changed my mind"
- Status: `CANCELED`
- Days remaining: 15
- Action: Resume current subscription
- Credit: None (already paid for 30 days)
- Implementation: Remove cancellation flag

**Story 2**: "I canceled but now I need more features"
- Status: `CANCELED`
- Days remaining: 15
- Action: Upgrade to higher plan
- Credit: Calculate 15 days × old plan price, apply to new plan
- Implementation: Full upgrade flow from Part 3

**Story 3**: "My subscription expired, I want to come back"
- Status: `EXPIRED`
- Days remaining: 0
- Action: Create new subscription
- Credit: None
- Implementation: Normal signup flow

## Reactivation Implementation

### 1. Resume Same Plan (Cancel Cancellation)

```typescript
// src/app/api/subscription/reactivate/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';

export async function POST(req: Request) {
  try {
    const { userId: clerkId } = await auth();
    if (!clerkId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    // Get user's subscription
    const user = await prisma.user.findUnique({
      where: { id: clerkId },
      include: {
        subscription: {
          include: { plan: true }
        }
      }
    });
    
    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No subscription found' },
        { status: 400 }
      );
    }
    
    const subscription = user.subscription;
    
    // Can only reactivate CANCELED subscriptions
    if (subscription.status !== 'CANCELED') {
      return NextResponse.json(
        { error: `Cannot reactivate ${subscription.status} subscription` },
        { status: 400 }
      );
    }
    
    // Check if period hasn't ended yet
    if (subscription.currentPeriodEnd < new Date()) {
      return NextResponse.json(
        { error: 'Subscription period already ended. Please create a new subscription.' },
        { status: 400 }
      );
    }
    
    // Reactivate in Razorpay
    let razorpayReactivated = false;
    
    if (subscription.razorpaySubscriptionId) {
      try {
        // Check if Razorpay subscription still exists
        const razorpaySub = await razorpay.subscriptions.fetch(
          subscription.razorpaySubscriptionId
        );
        
        // If canceled at cycle end, we can't reactivate in Razorpay
        // User will auto-renew at period end
        if (razorpaySub.status === 'cancelled') {
          console.warn('⚠️ Razorpay subscription already canceled');
        } else {
          // Update to not cancel at cycle end
          await razorpay.subscriptions.update(
            subscription.razorpaySubscriptionId,
            {
              schedule_change: {
                cancel: false
              }
            }
          );
          razorpayReactivated = true;
          console.log(`✅ Reactivated subscription in Razorpay`);
        }
      } catch (error) {
        console.error('❌ Razorpay reactivation error:', error);
        // Continue with DB update even if Razorpay fails
      }
    }
    
    // Update database
    await prisma.$transaction(async (tx) => {
      await tx.subscription.update({
        where: { id: subscription.id },
        data: {
          status: 'ACTIVE',
          canceledAt: null,
          metadata: {
            ...(subscription.metadata as any),
            reactivatedAt: new Date(),
            reactivationType: 'same_plan',
            razorpayReactivated
          },
          updatedAt: new Date()
        }
      });
      
      await tx.subscriptionHistory.create({
        data: {
          subscriptionId: subscription.id,
          action: 'REACTIVATED',
          fromStatus: 'CANCELED',
          toStatus: 'ACTIVE',
          reason: 'User reactivated canceled subscription',
          metadata: {
            type: 'reactivate_same_plan',
            razorpayReactivated,
            daysRemaining: Math.ceil(
              (subscription.currentPeriodEnd.getTime() - Date.now()) / (1000 * 60 * 60 * 24)
            )
          }
        }
      });
    });
    
    console.log(`✅ Reactivated subscription for ${user.email}`);
    console.log(`   Plan: ${subscription.plan.displayName}`);
    console.log(`   Access until: ${subscription.currentPeriodEnd.toDateString()}`);
    
    return NextResponse.json({
      success: true,
      message: 'Subscription reactivated successfully',
      details: {
        plan: subscription.plan.displayName,
        status: 'ACTIVE',
        accessUntil: subscription.currentPeriodEnd
      }
    });
    
  } catch (error) {
    console.error('❌ Reactivation error:', error);
    return NextResponse.json(
      { error: 'Failed to reactivate subscription' },
      { status: 500 }
    );
  }
}
```

### 3. Create New After EXPIRED

```typescript
// src/app/api/subscription/create-new/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';
import { 
  getBillingCycleCount,
  calculateNewPeriodEnd 
} from '@/lib/proration-calculator';

export async function POST(req: Request) {
  try {
    const { userId: clerkId } = await auth();
    if (!clerkId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const { planId, razorpayPaymentId } = await req.json();
    
    // Get user
    const user = await prisma.user.findUnique({
      where: { id: clerkId },
      include: { subscription: true }
    });
    
    if (!user) {
      return NextResponse.json({ error: 'User not found' }, { status: 404 });
    }
    
    // Check if user already has ACTIVE subscription
    if (user.subscription && ['ACTIVE', 'PAST_DUE', 'COMPLETING'].includes(user.subscription.status)) {
      return NextResponse.json(
        { error: 'You already have an active subscription. Use upgrade/downgrade instead.' },
        { status: 400 }
      );
    }
    
    // Get plan
    const plan = await prisma.subscriptionPlan.findUnique({
      where: { id: planId }
    });
    
    if (!plan) {
      return NextResponse.json({ error: 'Plan not found' }, { status: 404 });
    }
    
    // Verify Razorpay payment
    const payment = await razorpay.payments.fetch(razorpayPaymentId);
    
    if (payment.status !== 'captured' || payment.amount !== Number(plan.price) * 100) {
      return NextResponse.json(
        { error: 'Invalid payment' },
        { status: 400 }
      );
    }
    
    // Create Razorpay subscription
    const now = new Date();
    const periodEnd = calculateNewPeriodEnd(now, plan.billingCycle);
    
    const razorpaySub = await razorpay.subscriptions.create({
      plan_id: plan.razorpayPlanId!,
      customer_id: user.razorpayCustomerId!,
      total_count: getBillingCycleCount(plan.billingCycle),
      start_at: Math.floor(now.getTime() / 1000),
      notify: 1,
      notes: {
        userId: clerkId,
        subscriptionType: 'new_after_expired'
      }
    });
    
    // Create or update subscription
    await prisma.$transaction(async (tx) => {
      if (user.subscription) {
        // Update existing (EXPIRED/CANCELED)
        await tx.subscription.update({
          where: { id: user.subscription.id },
          data: {
            planId,
            razorpaySubscriptionId: razorpaySub.id,
            razorpayPlanId: plan.razorpayPlanId,
            razorpayCustomerId: user.razorpayCustomerId,
            billingCycle: plan.billingCycle,
            status: 'ACTIVE',
            currentPeriodStart: now,
            currentPeriodEnd: periodEnd,
            canceledAt: null,
            metadata: {
              createdVia: 'reactivation_new',
              previousSubscriptionId: user.subscription.razorpaySubscriptionId
            },
            updatedAt: now
          }
        });
        
        await tx.subscriptionHistory.create({
          data: {
            subscriptionId: user.subscription.id,
            action: 'REACTIVATED',
            toPlanId: planId,
            toStatus: 'ACTIVE',
            reason: 'Created new subscription after expiration',
            metadata: {
              type: 'new_after_expired',
              razorpaySubId: razorpaySub.id,
              paymentId: razorpayPaymentId
            }
          }
        });
      } else {
        // Create new subscription record
        const newSub = await tx.subscription.create({
          data: {
            userId: clerkId,
            planId,
            razorpaySubscriptionId: razorpaySub.id,
            razorpayPlanId: plan.razorpayPlanId,
            razorpayCustomerId: user.razorpayCustomerId,
            billingCycle: plan.billingCycle,
            status: 'ACTIVE',
            currentPeriodStart: now,
            currentPeriodEnd: periodEnd,
            metadata: {
              createdVia: 'first_subscription'
            }
          }
        });
        
        await tx.subscriptionHistory.create({
          data: {
            subscriptionId: newSub.id,
            action: 'CREATED',
            toPlanId: planId,
            toStatus: 'ACTIVE',
            reason: 'First subscription created',
            metadata: {
              razorpaySubId: razorpaySub.id,
              paymentId: razorpayPaymentId
            }
          }
        });
      }
    });
    
    console.log(`✅ Created new subscription for ${user.email}`);
    console.log(`   Plan: ${plan.displayName}`);
    console.log(`   Razorpay ID: ${razorpaySub.id}`);
    
    return NextResponse.json({
      success: true,
      message: 'Subscription created successfully',
      details: {
        plan: plan.displayName,
        status: 'ACTIVE',
        periodEnd
      }
    });
    
  } catch (error) {
    console.error('❌ Create subscription error:', error);
    return NextResponse.json(
      { error: 'Failed to create subscription' },
      { status: 500 }
    );
  }
}
```

## PAST_DUE Handling Strategies

### Understanding PAST_DUE

**When does it happen?**
- Razorpay auto-charge fails (card declined, insufficient funds, expired card)
- User's payment method invalid

**Razorpay's behavior**:
- Marks subscription as `past_due`
- Retries payment automatically (configurable)
- Sends webhooks: `subscription.charged` (failed)

**Your decision**: Give grace period or block immediately?

---

### Strategy 1: Grace Period (Recommended)

```typescript
// Allow limited access during PAST_DUE

async function checkSubscriptionAccess(userId: string): Promise<{
  hasAccess: boolean;
  reason?: string;
  graceDaysRemaining?: number;
}> {
  const user = await prisma.user.findUnique({
    where: { id: userId },
    include: { subscription: true }
  });
  
  if (!user?.subscription) {
    return { hasAccess: false, reason: 'No subscription' };
  }
  
  const sub = user.subscription;
  
  // ACTIVE = Full access
  if (sub.status === 'ACTIVE') {
    return { hasAccess: true };
  }
  
  // PAST_DUE = Grace period
  if (sub.status === 'PAST_DUE') {
    const GRACE_PERIOD_DAYS = 7; // Configurable
    const daysSinceFailure = Math.ceil(
      (Date.now() - sub.currentPeriodEnd.getTime()) / (1000 * 60 * 60 * 24)
    );
    
    if (daysSinceFailure <= GRACE_PERIOD_DAYS) {
      return {
        hasAccess: true,
        reason: 'grace_period',
        graceDaysRemaining: GRACE_PERIOD_DAYS - daysSinceFailure
      };
    } else {
      return {
        hasAccess: false,
        reason: 'Grace period expired. Please update payment method.'
      };
    }
  }
  
  // CANCELED, EXPIRED = No access
  return { hasAccess: false, reason: `Subscription ${sub.status.toLowerCase()}` };
}
```

**Pros**:
✅ Better UX (user doesn't lose data immediately)
✅ Higher retention (time to fix payment)
✅ Industry standard (Netflix, Spotify do this)

**Cons**:
❌ Potential abuse
❌ More complex logic

### Retry Payment Implementation

```typescript
// src/app/api/subscription/retry-payment/route.ts

import { NextResponse } from 'next/server';
import { auth } from '@clerk/nextjs/server';
import prisma from '@/lib/prismadb';
import razorpay from '@/lib/razorpay';

export async function POST(req: Request) {
  try {
    const { userId: clerkId } = await auth();
    if (!clerkId) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
    
    const { paymentMethodId } = await req.json();
    
    // Get user's subscription
    const user = await prisma.user.findUnique({
      where: { id: clerkId },
      include: {
        subscription: {
          include: { plan: true }
        }
      }
    });
    
    if (!user?.subscription) {
      return NextResponse.json(
        { error: 'No subscription found' },
        { status: 400 }
      );
    }
    
    const subscription = user.subscription;
    
    if (subscription.status !== 'PAST_DUE') {
      return NextResponse.json(
        { error: 'Subscription is not past due' },
        { status: 400 }
      );
    }
    
    // Update payment method in Razorpay
    if (paymentMethodId) {
      try {
        await razorpay.subscriptions.update(
          subscription.razorpaySubscriptionId!,
          {
            payment_method: paymentMethodId
          }
        );
        console.log(`✅ Updated payment method`);
      } catch (error) {
        console.error('❌ Failed to update payment method:', error);
      }
    }
    
    // Charge manually
    try {
      const charge = await razorpay.subscriptions.charge(
        subscription.razorpaySubscriptionId!
      );
      
      if (charge.status === 'captured') {
        // Payment successful - reactivate
        await prisma.$transaction(async (tx) => {
          await tx.subscription.update({
            where: { id: subscription.id },
            data: {
              status: 'ACTIVE',
              currentPeriodStart: new Date(),
              currentPeriodEnd: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000), // +30 days
              updatedAt: new Date()
            }
          });
          
          await tx.subscriptionHistory.create({
            data: {
              subscriptionId: subscription.id,
              action: 'REACTIVATED',
              fromStatus: 'PAST_DUE',
              toStatus: 'ACTIVE',
              reason: 'Payment retry successful',
              metadata: {
                chargeId: charge.id,
                amount: charge.amount
              }
            }
          });
        });
        
        console.log(`✅ Payment retry successful for ${user.email}`);
        
        return NextResponse.json({
          success: true,
          message: 'Payment successful! Subscription reactivated.',
          details: {
            status: 'ACTIVE',
            chargeId: charge.id
          }
        });
      } else {
        return NextResponse.json(
          { error: 'Payment failed. Please try a different payment method.' },
          { status: 400 }
        );
      }
      
    } catch (error) {
      console.error('❌ Charge failed:', error);
      return NextResponse.json(
        { error: 'Payment failed. Please check your payment method.' },
        { status: 400 }
      );
    }
    
  } catch (error) {
    console.error('❌ Retry payment error:', error);
    return NextResponse.json(
      { error: 'Failed to retry payment' },
      { status: 500 }
    );
  }
}
```

## Edge Case Matrix

| Scenario | Status | Action | Credit? | Notes |
|----------|--------|--------|---------|-------|
| **Cancel then reactivate same plan** | CANCELED → ACTIVE | Resume | No | Already paid |
| **Cancel then upgrade** | CANCELED → ACTIVE | Upgrade flow | Yes | Prorate remaining days |
| **Cancel then downgrade** | CANCELED | Block | N/A | User already canceling |
| **Expired then new** | EXPIRED → ACTIVE | Create new sub | No | Clean slate |
| **Payment failed** | ACTIVE → PAST_DUE | Grace period | No | Allow 7 days |
| **Grace expired** | PAST_DUE → EXPIRED | Block access | No | Must create new |
| **Mid-cycle upgrade** | ACTIVE → ACTIVE | Swap + charge | Yes | Prorate old plan |
| **Mid-cycle downgrade** | ACTIVE → ACTIVE | Schedule | No | At period end |
| **Scheduled downgrade then cancel** | ACTIVE | Remove schedule | No | Keep current |
| **Trial expired** | TRIAL → EXPIRED | Block | No | Must subscribe |
| **Multiple upgrades same day** | ACTIVE → ACTIVE | Allow | Yes | Each proration separate |
| **Downgrade with overages** | ACTIVE | Block | No | Force cleanup first |
| **Account credit covers full price** | ACTIVE | Auto-apply | Yes | ₹0 charge |
| **Account credit partial** | ACTIVE | Reduce charge | Yes | Charge remainder |

### Credit Application During Charge

```typescript
// src/lib/apply-credit-to-charge.ts

import prisma from '@/lib/prismadb';
import { Decimal } from '@prisma/client/runtime/library';

export interface CreditApplicationResult {
  originalCharge: number;
  creditApplied: number;
  finalCharge: number;
  remainingCredit: number;
  creditTransactionId?: string;
}

export async function applyCreditToCharge(
  userId: string,
  chargeAmount: number,
  reason: string,
  metadata?: any
): Promise<CreditApplicationResult> {
  const user = await prisma.user.findUnique({
    where: { id: userId },
    select: { accountCredit: true }
  });
  
  if (!user) {
    throw new Error('User not found');
  }
  
  const availableCredit = Number(user.accountCredit || 0);
  
  // No credit to apply
  if (availableCredit <= 0) {
    return {
      originalCharge: chargeAmount,
      creditApplied: 0,
      finalCharge: chargeAmount,
      remainingCredit: 0
    };
  }
  
  // Calculate how much credit to apply
  const creditToApply = Math.min(availableCredit, chargeAmount);
  const finalCharge = Math.max(0, chargeAmount - creditToApply);
  const remainingCredit = availableCredit - creditToApply;
  
  // Record transaction
  const creditTx = await prisma.$transaction(async (tx) => {
    // Update user balance
    await tx.user.update({
      where: { id: userId },
      data: {
        accountCredit: remainingCredit
      }
    });
    
    // Create transaction record
    const transaction = await tx.creditTransaction.create({
      data: {
        userId,
        amount: -creditToApply, // Negative = used
        type: 'PLAN_UPGRADE', // Or appropriate type
        reason,
        balanceBefore: availableCredit,
        balanceAfter: remainingCredit,
        metadata: {
          ...metadata,
          originalCharge: chargeAmount,
          creditApplied: creditToApply,
          finalCharge
        }
      }
    });
    
    return transaction;
  });
  
  console.log(`✅ Applied ₹${creditToApply} credit`);
  console.log(`   Original charge: ₹${chargeAmount}`);
  console.log(`   Final charge: ₹${finalCharge}`);
  console.log(`   Remaining credit: ₹${remainingCredit}`);
  
  return {
    originalCharge: chargeAmount,
    creditApplied: creditToApply,
    finalCharge,
    remainingCredit,
    creditTransactionId: creditTx.id
  };
}
```

## Migration Between Plan Types

### Scenario: Change Billing Cycle

**Example**: Monthly (₹3,500) → Half-Yearly (₹18,000)

**Challenge**: Different period lengths

**Solution**:

```typescript
// Treat as upgrade/downgrade based on price

const monthlyPrice = 3500;
const monthlyValue = monthlyPrice * 6; // ₹21,000 for 6 months
const halfYearlyPrice = 18000; // ₹18,000 for 6 months

if (halfYearlyPrice < monthlyValue) {
  // It's actually a "savings upgrade"
  // Calculate proration for remaining monthly days
  // Charge difference for half-yearly
} else {
  // Standard upgrade
}
```

**Implementation**:

```typescript
// src/lib/calculate-billing-cycle-change.ts

export function calculateBillingCycleChange(
  currentPrice: number,
  currentCycle: 'MONTHLY' | 'HALF_YEARLY' | 'YEARLY',
  newPrice: number,
  newCycle: 'MONTHLY' | 'HALF_YEARLY' | 'YEARLY',
  daysRemaining: number
): {
  isUpgrade: boolean;
  creditFromOld: number;
  chargeForNew: number;
  netCharge: number;
  savings?: number;
} {
  // Calculate daily rate for current plan
  const currentCycleDays = currentCycle === 'MONTHLY' ? 30 
    : currentCycle === 'HALF_YEARLY' ? 180 
    : 365;
  
  const dailyRateOld = currentPrice / currentCycleDays;
  
  // Credit for remaining days
  const creditFromOld = dailyRateOld * daysRemaining;
  
  // Full price for new plan
  const chargeForNew = newPrice;
  
  // Net charge
  const netCharge = chargeForNew - creditFromOld;
  
  // Determine if upgrade (paying more) or downgrade (paying less)
  const isUpgrade = netCharge > 0;
  
  // Calculate savings if switching to longer cycle
  let savings: number | undefined;
  if (newCycle !== 'MONTHLY' && currentCycle === 'MONTHLY') {
    const monthsInNewCycle = newCycle === 'HALF_YEARLY' ? 6 : 12;
    const monthlyEquivalent = currentPrice * monthsInNewCycle;
    savings = monthlyEquivalent - newPrice;
  }
  
  return {
    isUpgrade,
    creditFromOld: Math.round(creditFromOld * 100) / 100,
    chargeForNew,
```

### Rollback Strategy

```typescript
// src/lib/rollback-subscription-change.ts

export async function rollbackSubscriptionChange(
  subscriptionId: string,
  reason: string
): Promise<void> {
  console.log(`🔄 Rolling back subscription change: ${subscriptionId}`);
  console.log(`   Reason: ${reason}`);
  
  // Get subscription with history
  const subscription = await prisma.subscription.findUnique({
    where: { id: subscriptionId },
    include: {
      history: {
        orderBy: { createdAt: 'desc' },
        take: 1
      }
    }
  });
  
  if (!subscription) {
    throw new Error('Subscription not found');
  }
  
  const lastHistory = subscription.history[0];
  
  if (!lastHistory) {
    console.warn('⚠️ No history to rollback to');
    return;
  }
  
  // Rollback to previous state
  await prisma.$transaction(async (tx) => {
    await tx.subscription.update({
      where: { id: subscriptionId },
      data: {
        planId: lastHistory.fromPlanId!,
        status: lastHistory.fromStatus!,
        updatedAt: new Date(),
        metadata: {
          ...(subscription.metadata as any),
          rolledBackAt: new Date(),
          rollbackReason: reason,
          rolledBackFromHistory: lastHistory.id
        }
      }
    });
    
    await tx.subscriptionHistory.create({
      data: {
        subscriptionId,
        action: 'REACTIVATED', // Rolled back
        fromPlanId: lastHistory.toPlanId,
        toPlanId: lastHistory.fromPlanId,
        fromStatus: lastHistory.toStatus,
        toStatus: lastHistory.fromStatus,
        reason: `Rollback: ${reason}`,
        metadata: {
          type: 'rollback',
          originalHistoryId: lastHistory.id
        }
      }
    });
  });
  
  console.log(`✅ Rollback complete`);
}
```

```typescript
// In /api/subscription/upgrade/verify

try {
  // 1. Cancel old subscription

  console.error('❌ Upgrade failed:', error);
  
  // Attempt rollback
  try {
    await rollbackSubscriptionChange(
      subscription.id,
      error instanceof Error ? error.message : 'Unknown error'
    );
    
    return NextResponse.json(
      { error: 'Upgrade failed, changes rolled back' },
      { status: 500 }
    );
  } catch (rollbackError) {
    console.error('❌ Rollback also failed:', rollbackError);
    
    // Manual intervention needed
    await notifyAdminOfFailedRollback(subscription.id);
    
    return NextResponse.json(
      { error: 'Critical error - please contact support' },
      { status: 500 }
    );
  }
}
```

## Complete Flow Diagrams

### Master Plan Change Decision Tree

```
User requests plan change
         ↓
Identify current status
         ↓
    ┌────┴────┐
    │ Status? │
    └────┬────┘
         │
    ┌────┼────┬────────┬──────────┐
    │    │    │        │          │
  ACTIVE │  CANCELED  │      PAST_DUE
    │    │    │        │          │
    │    │    │   COMPLETING  EXPIRED
    │    │    │        │          │
    ↓    ↓    ↓        ↓          ↓
         
■ ACTIVE:
  → Upgrade? → Part 3 flow (immediate swap)
  → Downgrade? → Part 4 flow (scheduled/immediate)
  
■ CANCELED:
  → Reactivate same? → Resume (this part)
  → Upgrade? → Part 3 flow (prorate + upgrade)
  → Downgrade? → Block (already canceling)
  
■ PAST_DUE:
  → Retry payment → Charge manually
  → Upgrade? → Block until payment fixed
  
■ COMPLETING:
  → Upgrade? → Extend subscription
  → Downgrade? → Block (ending anyway)
  
■ EXPIRED:
  → Any plan? → Create new subscription
```

```
Credit Added
     ↓
CreditTransaction created (positive amount)
     ↓
User.accountCredit updated (+amount)
     ↓
[Credit sits in account]
     ↓

     ↓

┌─────────────────────┐

└──────┬──────────────┘
       │
   ┌───┴───┐
   │       │
  YES     NO
   │       │
   │       └─→ Charge full price
   │           No credit applied
   │
   └─→ Calculate: min(credit, charge)
       ↓
       Apply credit
       ↓
       CreditTransaction created (negative amount)
       ↓
       User.accountCredit updated (-amount)
       ↓
       Charge reduced amount (or ₹0 if fully covered)
```
